# Plotly Kline samples

These charts were generated by the implemented `KlineTSeries.plot()` method from
the existing CC master table. They preserve UTC timestamps and values. The default places recorded bars consecutively; `show_gaps=True` displays elapsed calendar time.

From the repository root, install the optional renderer with `uv sync --extra plot`.
Load a series through the class factory, then call its methods:

```python
from pathlib import Path
from chanlab.algo.kline import KlineTSeries

folder = Path("samples/chan_table")
series = KlineTSeries.read_csv(next(folder.glob("*chan_table*.csv")),
                              next(folder.glob("*context*.csv")))
# series.write_csv("raw.csv", "context.csv") preserves series.context.
fig = series.plot(start=-200, volume=True)  # Gaps hidden by default.
calendar_fig = series.plot(start=-200, show_gaps=True)
china_fig = series.plot(start=-40, volume=False, market="China")
fig.show()  # Caller chooses display; plot() itself only returns a Figure.
```

`start`/`stop` are Python slice positions; omitted bounds select all bars. An empty
selection raises `ValueError`. Set `volume=False` to omit the lower panel or pass
`title="..."` to replace the symbol/period title. Raw classes/CSV work without the
optional dependency; no DataFrame is required.

HTML contains its Plotly renderer and can be viewed offline. PNG previews were
exported with Kaleido and local Chrome in a temporary tool environment; these are
not required for interactive plotting or HTML export. Reproduce the samples
with `PYTHONPATH=src uv run --no-project --with plotly --with kaleido python
artifacts/kline/generate_samples.py` (a compatible Chrome is needed for PNG).
