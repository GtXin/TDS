完整时序候选决策树：暂定端点、强制延伸、备选恢复

2.1 输入与初始起点检查
├── 2.1.a 完整分型少于两个
│   → 返回“暂无完整笔”和未决范围，结束
└── 2.1.b 至少两个
    → 将每个可能的初始起点列为待试分支；
      先取最早的A，B未定，已有笔为空；其余分支缓存；转2.2

2.2 下一分型检查
├── 2.2.a 仍有下一完整分型F
│   → 读取F，把检查位置移到F之后；转2.3
└── 2.2.b 完整分型已耗尽
    → 本分支以“输入耗尽”进入2.8

2.3 当前工作阶段检查
├── 2.3.a B未定：正在寻找当前笔的终点
│   └── 2.4 A→F成笔条件检查
│       ├── 2.4.a 不合格
│       │   → 保留F及本次失败原因；A不变，回2.2
│       └── 2.4.b 合格
│           → 缓存“本次不选F、保留A、从下一位置继续找B”的备选；
│             当前取B=F，保留A，进入等待反向C阶段；回2.2
│             ［此时不固定B，也不立即输出完成笔］
└── 2.3.b B已暂定：正在等待合格反向C
    └── 2.5 F与B的类型检查
        ├── 2.5.a 同型 → 转2.6
        └── 2.5.b 异型 → 转2.7

2.6 同型端点延伸检查
├── 2.6.a F比B更极端：顶更高，或底更低
│   → 重新检查完整的A→F
│   ├── 2.6.a.1 合格
│   │   → 记录旧B的历史，以F更新B；A不变；回2.2
│   │     ［当前路线必须延伸，不保留“跳过更优F仍沿用旧B”的分支］
│   └── 2.6.a.2 不合格
│       → 记录F、失败原因和历史有效片段；
│         当前路线不能沿旧B继续覆盖后续，标记阻塞；转2.8
├── 2.6.b F与B端点价格相等
│   → 检查A→F
│   ├── 2.6.b.1 合格
│   │   → 缓存“改取B=F、从下一位置继续”的备选；
│   │     当前保留旧B，回2.2；两支独立考察
│   └── 2.6.b.2 不合格
│       → 保留F及失败原因；当前B不变，回2.2
└── 2.6.c F不如B极端
    → 保留F供其他路线重查；当前B不变，回2.2

2.7 反向笔检查
├── 2.7.a B→F不合格
│   → 缓存F及相对B的失败原因；A、B均不变，回2.2
└── 2.7.b B→F合格
    → F成为本工作状态下首个合格反向C；
      将A→B暂存为本分支已有笔，记录路径检查点；
      以旧B作为新A，以C作为新B，继续等待下一反向端点；回2.2
      ［B→C仍是可延伸的工作笔，此前路径也允许经备选恢复而重选］

2.8 当前分支收尾与备选恢复
→ 先按进入原因处理
├── 2.8.a 输入耗尽
│   ├── B已暂定
│   │   → 保留“已有笔＋当前A→B”为一条候选路线；
│   │     当前工作笔标为暂定；头尾未覆盖范围单独保留
│   └── B仍未定
│       → 孤立起点不计作笔，保留未决范围
└── 2.8.b 延伸失败，当前路线阻塞
    → 仅保存历史有效片段和阻塞依据；
      不把该片段冒充已处理后续行情的可行路线
→ 再检查备选缓存
├── 2.8.c 还有未执行的备选
│   → 取最近的未执行备选；恢复其完整路径、A/B、阶段及下一检查位置；
│     执行该备选已经指定的不同选择，复核工作对及已有连接；
│     通过后回2.2；恢复状态不一致则报错，停止
│     ［恢复后从该位置按时间重查，不重开同一个选择］
└── 2.8.d 所有备选均已执行
    → 转2.9

2.9 最终结果检查
├── 2.9.a 没有可行候选路线
│   → 返回“暂无可保留的候选路线”，附历史片段、阻塞依据及未决范围；结束
└── 2.9.b 存在可行候选路线
    → 复核每根笔及共享端点、方向交替；不合格则报错，停止；
      合格则合并端点序列完全相同的重复结果，按相同起终点分组；
      组内一条标记唯一，多条全部保留并标记多解；
      返回候选路线、暂定工作笔和各自未决范围，结束
