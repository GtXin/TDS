笔的完整候选划分决策树（六条件基准）

2.1 完整分型数量检查
├── 2.1.a 少于两个
│   → 返回“暂无完整笔”，保留未决范围，结束
└── 2.1.b 至少两个
    → 从最早分型开始尝试初始起点A；本次尚未选入任何笔；转2.2

2.2 后续分型检查
├── 2.2.a 仍有尚未检查的后续分型B
│   → 取本轮B，转2.3
└── 2.2.b 后续分型已耗尽
    → 已有完整笔则保留本分支的候选划分；
      孤立起点不计作笔；未覆盖头尾保持未决；转2.8

2.3 A、B类型检查
├── 2.3.a 同为顶，或同为底
│   → 本对不能成笔；A不变，检查下一B，回2.2
└── 2.3.b 一顶一底
    └── 2.4 分型间隔检查
        ├── 2.4.a c(B)−c(A)<4
        │   → 没有独立合并K线；检查下一B，回2.2
        └── 2.4.b c(B)−c(A)≥4
            → 两端三根窗口之间至少有一根独立合并K线
            └── 2.5 两端中心K线区间检查
                ├── 2.5.a H顶≤H底，或L底≥L顶
                │   → 区间关系不成立；检查下一B，回2.2
                └── 2.5.b H顶>H底，且L底<L顶
                    └── 2.6 笔内极值检查
                        ├── 2.6.a 存在high>H顶或low<L底
                        │   → 端点不是范围极值；检查下一B，回2.2
                        └── 2.6.b 全部high≤H顶且low≥L底
                            → A→B是合法候选笔
                            └── 2.7 端点选择［两支均须考察］
                                → 两支从同一选择前状态分别开始
                                ├── 2.7.a 选B
                                │   → 接上A→B；
                                │     先底后顶为向上笔，先顶后底为向下笔；
                                │     将B作为新起点A，从其后继续，回2.2
                                └── 2.7.b 暂不选B
                                    → 保留原A和已有笔；检查下一B，回2.2

2.8 剩余选择检查
├── 2.8.a 当前初始起点下，还有未检查的选择分支
│   → 撤销已完成分支的临时选择；
│     恢复选择前的已选笔、A及检查位置；
│     转入2.7尚未检查的分支
├── 2.8.b 当前起点所有分支已查完，还有其他初始起点
│   → 取下一分型为初始起点A，本次重新从未选笔开始；
│     从A之后检查，回2.2
└── 2.8.c 所有初始起点和分支均已检查
    → 复核各候选划分的六项条件；
      若不符，指出矛盾并停止输出；通过后转2.9

2.9 结果检查
├── 2.9.a 没有合法候选划分
│   → 返回“暂无完整笔”，保留未决范围，结束
└── 2.9.b 存在合法候选划分
    → 按相同起终点分组，逐组检查
    ├── 2.9.b.1 组内只有一种划分
    │   → 标记“该起终点范围内唯一”
    └── 2.9.b.2 组内存在多种划分
        → 全部保留，标记“该起终点范围内多解”
    → 返回全部分组结果及各自未决范围，结束
