### 002.a — Algorithm Tree

从左到右读取全部完整分型，依次维护待定起点、缓存笔和已提交结果。普通配对失败继续读取；R只追加；EOF保留未完成缓存。成笔条件采用001版本二的六项定义，距离使用本次选定档位。

**输入、位置与状态**

输入`source`为同一不可变快照中的全部完整分型及其确切合并K线来源。合并来源非空、相邻无包含；每个分型三根窗口齐备，按中心位置严格递增。完整分型不表示走势已永久确认。价格比较使用输入原精度。

| 记号 | 含义 |
|---|---|
| fx、merged；M、N | 完整分型序列、确切合并来源；两者长度分别为M、N。N至少1，M可以0。 |
| F、S、A、B | 伪代码中均指fx中的零基位置，不是分型ID、合并位置或原始锚点。`c(X)=fx[X].source_start+1`才是合并中心。 |
| Bi001S、Bi001E | 下一笔的起终点工作状态。无缓存时S是首笔待定起点；有缓存时S等于当前缓存终点B。每轮动作结束后E均未定。 |
| Bi002 | 已满足几何条件、尚未提交的缓存笔A→B；首笔形成前为空。 |
| R | 已提交笔的不可变端点对序列；只追加旧缓存当时的独立端点值，后续不修改已有记录。 |
| next_position | 下一未读完整分型在fx中的位置；每读一个分型增加1，正常EOF时等于M。 |

**距离选项与续读**

`distance_mode`可显式指定`"strong"`或`"weak"`，由此唯一得到`min_gap=4`或`3`，不另开放任意距离值。`None`只表示未指定：初次处理取强档，续读继承Q中的档位。未知值、缺少档位的旧Q、档位与门槛不一致、续读显式改档均报错，即使R为空也不例外。

初次弱档写作`process(source, distance_mode="weak")`；以后可用`process(new_source, previous_state=Q)`继承弱档。要更换档位，从完整输入重新计算另一结果版本，不修改原Q或原R。距离强弱、同型端点价格强弱及附录B的`bi_strong`分别定义。

**输出与续读使用同一份快照Q。** Q是普通不可变数据，不新增领域类或BiSeries接口。`process(source, distance_mode=None)`返回Q；下一批调用`process(new_source, previous_state=Q)`，不需要调用者重新拼装状态。

| Q中保存的内容 | 约定 |
|---|---|
| R、Bi002、Bi001S、Bi001E、next_position | 以上工作状态的独立不可变值；Bi001E为None。有缓存时仍保存S=B，不能把S误作额外一根笔。 |
| source_context | 当前整个输入快照及其来源链，或足以核对的完整前缀、长度与上下文；包括原始、合并、完整分型和算法／规则、配置、精度信息；必须显式保存本次有效distance_mode与派生min_gap。不能只保存R端点或已检查区间。 |
| evidence | 已读分型的实际判断依据，按读取顺序保存；一个分型只记录一次，首个起点也有初始化依据；距离比较记录实际中心距与本档min_gap。仅记录稳定的FX／来源位置、实际比较与动作，不写调用时间、批号、当批N或快照对象身份；整个来源由source_context统一保存。EOF说明属于本次展示信息，不反复追加到这里。 |
| unresolved | 按当前N重新计算的未覆盖合并范围。无缓存时是`[0,N)`；有缓存时是首笔起点以前及缓存终点以后。 |

续读只接受本过程在同一规则与输出约定下正常返回、未被改写的Q。新快照可以是新对象，但上一批**整个**原始／合并／完整分型前缀及稳定上下文必须保持；标的、周期、精度、配置与规则不能偷换。历史缩短或修订时拒绝直接续用Q，修订后的重算策略另行处理。新出现的完整分型中心可以落在上批未决尾部，故从保存的FX读取位置续读，不能按“中心必须大于旧N”过滤。

**按阶段简化成笔检查**

| 阶段 | 实际需要检查 |
|---|---|
| 首笔：F与S异型 | 中心距离至少min_gap；F为两中心闭区间对应的最高顶／最低底。S侧极值由逐个初始化选择保证。 |
| 延伸：合格A→B，F与B同型 | 较弱F直接略过；同价或更极端F只检查`(c(B),c(F)]`的上下两界。不重复距离或已合格前缀。 |
| 反向：F与B异型 | 中心距离至少min_gap；B和F分别是两中心闭区间的最高顶与最低底，两侧均查。 |

顶更高、底更低称“更极端”，同价不算更极端。初始化同价保留旧S；延伸同价须通过新增段检查后才替换B。类型、时间关系及端点区间不重复检查的依据见003；2.9仍按001独立完整验收。

**判断树：条件 → 动作 → 下一步**

2.x为算法步骤编号，S、E分别简写Bi001S、Bi001E。2.7是缓存成功改动后的共用检查入口。

```text
笔算法
├── 2.1 输入与续读状态检查
│   ├── 输入无效，或旧Q／距离选项非法、来源不兼容、状态被改写
│   │   → 报错，停止；不将其当作普通“暂无笔”
│   └── 检查通过，解析本次distance_mode及min_gap
│       ├── 初次处理
│       │   → R、Bi002为空；S、E未定；next_position=0；依据为空
│       └── 续读
│           → 从Q恢复R、Bi002、S、E、next_position及依据；不清空R
│       → 若S未定且有首个新完整分型：以它初始化S，
│         读取位置增加1，记录初始化依据；随后转2.2
│         ［若仍无完整分型，也转2.2，由EOF分支正常收尾］
│
├── 2.2 下一分型检查
│   ├── 2.2.a next_position<M，仍有分型F
│   │   → 读取F，位置增加1；本轮判断依据只保存一次
│   │   ├── Bi002为空
│   │   │   └── 2.3 首笔初始化：F与S比较
│   │   │       ├── 2.3.a 同型
│   │   │       │   ├── F更极端 → S=F；记录比较；回2.2
│   │   │       │   └── 较弱或同价 → 保留S；记录比较；回2.2
│   │   │       └── 2.3.b 异型
│   │   │           → 查中心距≥min_gap及F侧范围极值
│   │   │           ├── 不通过 → 保留S；记录失败依据；回2.2
│   │   │           └── 通过
│   │   │               → Bi002=(旧S→F)；S=F；E未定；
│   │   │                 R仍空；记录依据；转2.7
│   │   └── Bi002存在
│   │       └── 2.4 令A=Bi002S，B=Bi002E=S
│   │           ├── F与B同型
│   │           │   └── 2.5 缓存终点延伸检查
│   │           │       ├── F比B弱 → 不扫描区间；记录比较；回2.2
│   │           │       └── 同价或更极端
│   │           │           → 查(c(B),c(F)]各根K线的上下两界
│   │           │           ├── 不通过
│   │           │           │   → 保持缓存与R；记录失败依据；回2.2
│   │           │           └── 通过
│   │           │               → Bi002E=F；同步S=F；E未定；
│   │           │                 记录依据；转2.7
│   │           └── F与B异型
│   │               └── 2.6 下一反向笔检查
│   │                   → 查中心距≥min_gap及B、F两侧全范围极值
│   │                   ├── 2.6.a 不通过
│   │                   │   → 保持缓存与R；记录失败依据；回2.2
│   │                   └── 2.6.b 通过
│   │                       → E=F；将旧(A,B)的独立端点值追加到R；
│   │                         新Bi002=(B,F)；S=F；清空E；
│   │                         记录依据；转2.7
│   └── 2.2.b next_position=M，没有下一分型 → 转2.8
│
├── 2.7 局部状态自检［不重扫K线］
│   → Bi002E=S、E未定；R非空时末笔终点=Bi002S且方向相反
│   ├── 不满足 → 内部状态错误，报错停止
│   └── 满足 → 回2.2
│
├── 2.8 本批输入耗尽：正常收尾
│   → 不把Bi002追加到R；保留S和读取位置；
│     按当前N计算未决范围，保存当前来源及距离档位／门槛；
│     EOF不追加分型判断依据；组装独立不可变Q；转2.9
│
└── 2.9 输出前独立复核
    → 按001本档复核Q.R及Q.Bi002，核对配置、连接、状态与未决范围
    ├── 失败 → 内部状态错误，报错停止
    └── 通过 → 返回Q；当前调用结束，不在EOF原地等待
```

未读到新分型时，R、Bi002、S、读取位置及分型依据不变；若只增加合并尾部，Q的来源上下文与未决范围仍按当前输入更新。对完全相同的输入与Q重复调用，返回内容相同。画图可连接R与Bi002，但必须区分未提交缓存及其后未决行情。

R的“不再修改”是本算法的提交约定；合格反向笔出现时提交旧缓存。允许末笔开放不等于保证未来必能完成，也不等于已经证明作者意义的永久确认。完整数值过程见002.b，函数契约和伪代码见002.c、002.d。
