## 003 — Reasoning (Why)

### 推理与判断

1. **初始化与延伸分开。** Bi002为空时，只维护待定起点，原2.b没有终点C。若新同型点更极端，旧起点与其后任何反向端点连接都会包含这个新极值，所以按原2.a更新起点有依据。较弱／同价点不替换则是原note的局部选择策略；本树沿用它，不把另有合法起点当作该动作违反成笔条件的证据。
2. **完整检查已约束延伸方向。** Bi002=A→B合格后，B位于A→F的检查范围内；若同型新顶F更低，或新底F更高，A→F就不能通过端点极值检查。因此原5.a不必靠额外比较才能排除较弱替换。同价且合格时按原5.a取较晚端点；初始化同价则仍按原2.b保留较早起点，两阶段政策不同。
3. **只对原5.b的一类失败增加受阻出口。** 若B是顶、新F更高，对任意F之后的反向端点D，B→D都包含高于B的F，B不再是最高点；底更低时对称。若A→F又不能合格，沿旧B等待反向笔便无法跨过F续接当前路线。本轮建议保留合法历史并报告受阻，给后续恢复设计留下明确入口，不擅自引入全路线搜索或改换起点。[状态审查](../../artifacts/mas/bi-note-tree-v2/theory-review.md)
4. **记录与永久确认分开。** 原6.a的“确定笔”在本轮落实为将旧缓存笔记入R；它已经满足几何条件。写入后继续维持共享端点和方向交替，但仅有一根合格反向笔，还未证明前笔在任何未来恢复策略下都不可撤销，也不直接赋予生产Bi确认状态。
5. **合法性与终止范围。** 首笔通过完整检查才入缓存；延伸重新检查完整范围；反向通过后才记录旧笔并滚动，故有效R和Bi002始终满足单笔与连接条件。每次正常读取只向前一位，受阻立即收尾，有限输入保证终止。若完整配对直接扫描区间，本层朴素检查和最终复核最坏为`O(MN)`，M为分型数、N为合并K线数；工作笔数量固定，结果存储随笔数增长，不能仅因顺序读取就宣称总时间`O(M)`。

### 原5.b的阶段内边界例

给定连续21根合并K线`[low,low+1]`，low依次为：

```text
8,9,6,4,2,0,2,4,6,7,3,-1,1,3,5,8,5,2,0,-2,-1
```

全部分型中心为顶1、底5、顶9、底11、顶15、底19。按原note已先形成1→5，再由合格5→9触发滚动；此时R为1→5，缓存A=底5、B=顶9。底11与顶9距离2，反向不成笔。随后顶15最高9高于B的8，但5→15内部底11最低−1低于A的0，完整延伸失败。若仍沿顶9等待，任何晚于顶15的反向笔都会包含更高顶15，因而不能以顶9为最高端点。

本树在顶15处返回已记录1→5、原合法缓存5→9及受阻原因，底19尚未读取；不会删除这两段合法历史，也不把它们声称为已覆盖后续行情的完整结果。该例发生在已有缓存笔之后，与初始化2.b无关。[算术及状态核验](../../artifacts/mas/bi-note-tree-v2/numeric-review.md)

### 与004原note的异同

| 原note | 本树处理 | 性质与理由 |
|---|---|---|
| 1.a、2.a、2.b：从首个分型维护起点，同型更极端才更新 | 保留；同价也不替换 | 沿用原初始化策略，不使用第一轮的全局起点预查 |
| 3.a：首笔合格后进入Bi002 | 保留；补齐3.b“不合格继续读” | 补齐跳转，不改变选择顺序 |
| 4.a、5.a：同型且完整成笔就同步更新终点及下一起点 | 保留；明确同价合格取较晚端点 | 完整极值检查已排除严格较弱端点 |
| 5.b：不成笔就继续读 | 较弱／同价失败继续；更极端失败则保留历史并返回受阻 | 对原5.b的实质调整；旧终点不能跨越新极值继续续接 |
| 4.b、6.a、6.b：反向合格则记录前笔并滚动 | 保留；先赋Bi001E，再记录旧端点、滚动并清空新E | 补齐赋值顺序及缓存复用边界，维持共享端点 |
| 6.a：“确定笔” | 本轮称“已记录的几何合法笔” | 保留入结果动作，永久确认及未来撤回规则尚待定义 |
| 未写明的输入与结尾 | 增加无分型／单分型、非法输入、EOF、受阻及输出复核 | 完成有限输入的出口；末笔仍暂定，未决行情单列 |

本轮选择原note的单主路线推进，不加入候选路线枚举、合格反向点跳过分支或自动恢复；如进一步要求受阻后仍覆盖行情，需另行提出具体恢复规则并在原阶段验证。
