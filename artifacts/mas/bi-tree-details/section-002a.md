### 002.a — Algorithm Tree

本轮以004的原note和更新后提示词为基础，按“初始化起点 → 缓存首笔 → 延伸终点／形成反向笔 → 向前滚动”生成一条主路线。普通配对失败继续读下一分型；已提交到R的笔保持不变；本批数据结束时，最后一笔可以未完成并留在缓存中。本节为算法草案，现有028及代码仍对应附录C的第一轮实现。

**输入与工作状态**

本批输入为同一固定序列中的合并K线及全部完整分型，分型按中心位置严格递增；完整指三根窗口齐备，不表示走势已永久确认。价格比较使用输入原精度。后续只在已读合并K线、完整分型及来源上下文均保持原前缀的追加输入上续读；上游改写历史输入时，须另行处理输入修订，不能静默复用旧缓存。

| 记号 | 含义 |
|---|---|
| F | 本次新读分型；对应原note初始化阶段的B，或已有缓存笔阶段的C。 |
| Bi001S、Bi001E | 正在寻找的下一笔起终点；通常只有S，E未定。 |
| Bi002 | 已合格、仍可延伸的缓存笔；首笔形成前为空。 |
| A、B | 仅在Bi002存在时，分别表示它的当前起点和终点，不固定指向最初分型。 |
| R | 已提交的最终笔序列；只追加旧缓存笔当时的端点对，后续遍历及缓存复用均不修改已有记录。 |
| 下一读取位置 | 指向尚未处理的完整分型；EOF时一并保留，追加数据后从这里续读。 |

**按阶段简化成笔检查。** 001的六项定义不变。输入是全部完整严格分型且按时间读取时，时间顺序和分支中的类型关系已经成立；共享端点与交替方向由滚动赋值维持。两端区间关系可由严格分型和范围极值推出，不重复检测；依据见003。

| 当前阶段 | 实际需要检查 |
|---|---|
| 首笔：Bi002为空，F已知与Bi001S异型 | 中心距离至少4；F为两中心闭区间内对应的最高顶／最低底。当前起点自身的极值由初始化规则保证。 |
| 延伸：已合格A→B，F与B同型 | F若较弱直接不采用；同价或更极端时，只检查合并区间`(c(B),c(F)]`的高低点是否落在A与F的新上下界内。不再检查距离或重扫已合格的`[c(A),c(B)]`。 |
| 反向：F已知与B异型 | 中心距离至少4；B和F分别为两中心闭区间内最高顶和最低底，两侧极值都要检查。 |

顶更高、底更低称“更极端”；同价不算更极端。`c(X)`为分型中心的合并K线位置。延伸的新区间始终从当前缓存终点B之后算起，包含其间所有已读但未采用的分型和合并K线，不只检查上一个候选之后的部分。

**判断树：条件 → 动作 → 下一步**

以下2.x为同一棵树中的算法步骤编号；E为Bi001E。2.7是各成功更新分支共用的检查入口。

```text
笔算法［初次入口2.1；续读按下方约定进入2.2］
├── 2.1 初次扫描：输入检查与初始化
│   ├── 输入无效：相邻包含、分型不完整、漏报或顺序／来源不一致
│   │   → 报错，停止；不把无效输入当成“暂无笔”
│   └── 输入有效
│       → R、Bi002为空；Bi001S、Bi001E未定；下一读取位置=0
│       ├── 没有完整分型 → 转2.8
│       └── 至少一个完整分型
│           → Bi001S=第一个分型；下一读取位置设为第二个分型
│           └── 2.2 下一分型检查［续读也进入这里，不清空原状态］
│               ├── 2.2.a 仍有下一分型F
│               │   → 读取F，将下一读取位置移到F之后
│               │   ├── Bi002为空
│               │   │   └── 2.3 首笔初始化：F与当前Bi001S比较
│               │   │       ├── 2.3.a 同型
│               │   │       │   ├── F更极端
│               │   │       │   │   → Bi001S=F；E仍未定；回2.2
│               │   │       │   └── F较弱或同价
│               │   │       │       → 保留起点，本次不采用F；回2.2
│               │   │       └── 2.3.b 异型
│               │   │           → 检查中心距离至少4，且F为两中心范围的对应极值
│               │   │           ├── 不通过 → 保留起点，继续寻找首笔终点；回2.2
│               │   │           └── 通过
│               │   │               → Bi002=(旧Bi001S→F)；Bi001S=F；E未定；
│               │   │                 R仍为空；转2.7
│               │   └── Bi002存在
│               │       └── 2.4 令A=Bi002S，B=Bi002E=Bi001S
│               │           ├── F与B同型
│               │           │   └── 2.5 缓存终点延伸检查
│               │           │       ├── F比B弱
│               │           │       │   → 不替换终点，不扫描区间；回2.2
│               │           │       └── F与B同价或更极端
│               │           │           → 只检查(c(B),c(F)]各根K线：
│               │           │             high≤新顶端点high，low≥新底端点low
│               │           │           ├── 通过
│               │           │           │   → Bi002E=F；同步Bi001S=F；
│               │           │           │     E保持未定；转2.7
│               │           │           └── 不通过
│               │           │               → Bi002、Bi001S、R不变；
│               │           │                 保留失败依据；回2.2
│               │           └── F与B异型
│               │               └── 2.6 下一反向笔检查
│               │                   → 检查中心距离至少4；B、F分别为
│               │                     两中心闭区间的最高顶与最低底
│               │                   ├── 2.6.a 不通过
│               │                   │   → Bi002、Bi001S、R不变；
│               │                   │     保留失败依据；回2.2
│               │                   └── 2.6.b 通过
│               │                       → Bi001E=F，形成下一笔B→F；
│               │                         先将旧Bi002的独立端点对追加到R；
│               │                         再令Bi002=B→F；Bi001S=F；
│               │                         清空Bi001E；转2.7
│               │                         ［旧笔已提交不再改，新缓存仍可延伸］
│               └── 2.2.b 没有下一分型 → 转2.8
│
├── 2.7 共用入口：局部状态自检［不重扫K线］
│   → 检查Bi002E=Bi001S，Bi001E未定；R非空时，
│     R末笔终点=Bi002S，且末笔与缓存笔方向相反
│   ├── 不满足 → 内部状态错误，报错停止
│   └── 满足 → 回2.2
│
├── 2.8 本批输入耗尽：正常收尾
│   ├── Bi002为空
│   │   → 记录“尚无合格首笔”；保留待定起点（若有）及全部未决范围
│   └── Bi002存在
│       → 保留最终R、未完成Bi002及Bi001S；不强行闭合末笔；
│         不因EOF把Bi002追加到R；首端点以前、缓存终点以后保留为未决
│   → 保留下一读取位置及尚未采用分型的失败依据；转2.9
│
└── 2.9 输出前独立复核
    → 按001原定义复核R及Bi002（若有），包括共享端点与交替方向
    ├── 失败 → 内部状态错误，报错停止
    └── 通过
        → 返回最终R、未完成Bi002、待定起点、下一读取位置及未决范围；
          画图须区分未完成末笔及其后未决行情；
          本批正常结束，等待新数据，不在EOF原地空循环
```

**追加输入时的入口。** 保留原R和全部工作状态，不重新执行清空状态的初始化。若Bi001S未定且Bi002为空，R应为空：有首个新完整分型时，先以它初始化Bi001S并推进读取位置，随后转2.2；仍无分型则正常返回。其余情况从原下一读取位置进入2.2。有无新增分型都不制造缺少右邻K线的分型，也不在原输入耗尽后反复空读。

本树按原6.a在合格反向笔出现时提交旧缓存笔，提交后的R只增不改；这是本算法的结果边界，不等同于已证明作者意义的永久确认。本轮不增加候选路线枚举或回退重选。末笔及其后行情可以未决；允许EOF保留未完成状态，不等于保证固定缓存以后必然完成，也不等于要求每批数据闭合全部行情。

逐点数值推演及同价、EOF与续读例见002.b；辅助函数和对应伪代码见002.c、002.d。
