## 001 — Definition (What)

以下是根据附录A原文整理的综合定义，不是作者单句原话；附录B的CC实现规则不作为原文定义。

**线段是在已经成立的笔序列中，按特征序列的两类破坏规则划分出的有方向的连续笔组合。它至少包含三笔，开始三笔具有共同的价格重叠区间，首尾笔方向相同，两端为一底一顶且顶高于底；其完成需要由反向线段的破坏来确认。**[1–4]

1. **组成与方向。** 各笔按时间连续、首尾相接、方向交替，笔数为至少三笔的奇数。向上线段由向上笔开始、向上笔结束，两端为底到顶；向下线段相反。两端的顶必须高于底。[3][4]
2. **首三笔重叠。** 开始三笔的价格区间必须有共同交集；不要求整段所有笔都有共同交集。首三笔重叠是必要条件，不能仅凭三笔重叠就确认线段成立或完成。[3]
3. **特征序列。** 向上线段取向下笔作为特征序列，向下线段取向上笔。按适用的包含处理规则得到标准特征序列；包含处理须遵守同一序列的前提，以及假设分界点两侧与第二特征序列的不同要求。[1][2][4]
4. **完成条件。** 向上线段考察特征序列顶分型，向下线段考察底分型。构成分型的第一、第二元素间无缺口时，按第一类破坏规则确定结束；有缺口时，还需从候选转折点开始的反向结构，其第二特征序列出现相应分型，才能确定结束。第二特征序列的分型不再递归区分两类。具体应用须结合首三笔重叠、包含及笔破坏失败的补充条件，不能只凭一个外形分型判断。[1–4]
5. **笔破坏与暂定状态。** 一笔破坏不等于线段完成；反向结构未形成有效线段破坏时，原段仍可能延续。尚未获得足够确认依据的划分只作暂定标记；端点所在时间与确认该端点的时间不同。[2–4][6]
6. **原始端点与标准化。** 原文允许线段最高或最低点不在端点，因此不把“向上线段终点必须是整段最高点”加入原始定义。把线段作为后续中枢等分析的基本部件时，可以标准化为向上线段最低点开始、最高点结束，向下相反；该处理不替代原始划分规则。[4]
7. **前后段关系与实现边界。** 除最初起段外，划分还须满足后一段破坏前一段的关系，不能把满足基本形状条件的孤立笔组直接当作已确认线段。CC的候选、冻结、端点极值检查及可选变体是具体实现选择，不全部纳入上述原文定义。[4] 代码行为见附录B。

## 002 — Algorithm (How)

### 002.a — 算法问题陈述

从按时间排列、首尾相接、方向交替的合法笔中，选择部分笔端点作为线段端点，得到一条连续的上行／下行线段路线。沿用memo029的固定快照与选路优先级；每段是否成立和完成，仍完整遵守001，不能把笔的配对条件直接改名用于线段。

1. **输入与成员。** 笔序列记为Bi[0…N−1]，其共享端点记为P[0…N]；Bi[k]连接P[k]与P[k+1]。候选段S(i,j)从P[i]到P[j]，成员是连续的Bi[i:j]，i、j均为端点位置而非笔ID。允许跳过中间点作为线段端点，但不能跳过其中的笔或遗漏行情。输入保留确切上游路线、价格、方向和来源映射；本次计算中来源不变。上游strong／weak属于输入笔的版本，不作为线段新增距离条件。
2. **基本形状。** j−i为至少3的奇数；首尾笔同向，P[i]、P[j]为对应的一底一顶且顶高于底；开始三笔具有共同价格重叠区间。这些只给出候选资格，不等于线段完成。端点不强制为整段最高／最低点，内部每笔仍参与特征序列和破坏判断。[3][4]
3. **完成依据与相容性。** 选入已完成路线的每段都须取得001规定的第一类或第二类破坏依据，并与路线中实际采用的前后分界相容。无缺口时按完整第一类条件判断；有缺口时补查第二特征序列，第二分型不再递归区分两类。不能把相邻两个满足基本形状的笔组直接连接成已完成路线，也不能无条件要求第三个完整线段才确认前段。[1–4]
4. **选择目标。** 按起点位置由早到晚，固定至少存在一条非空合法已完成路线的最早起点；不为更晚起点可能走得更远而舍弃它。在该起点的合法连通路线中，先取几何终点最晚者，再取同一终点下已完成线段数最多者。不能为增加段数而牺牲终点；同分时按固定遍历顺序保留先找到的路线。这是本项目拟采用的选择规则，不作为作者原文或天然唯一性的结论。
5. **几何范围与证据范围。** 每段记录起终点、成员笔范围、特征元素的来源、破坏类别及证据读到的位置。确认P[j]的证据可以位于j之后，但不得因此把该段几何终点改为证据位置。后续证据可以属于下一段或尚未完成的尾部；跨段引用必须与选中划分一致，不能互相循环证明完成。[1–4][6]
6. **末尾与空结果。** 只把已取得合法完成依据的线段计入上述终点比较和段数；满足基本形状但证据不足的候选单独保留，不包装为已完成段。首段以前、最后已完成段以后仍可有未覆盖行情；其中被用作确认证据的笔仍未必被已完成路线覆盖。没有已完成路线时返回空路线及未决结构；普通候选失败继续搜索，EOF不强行闭合，也不保证未来必能闭合。
7. **固定快照边界。** 选路过程允许调整尚在计算中的前缀，不沿用此前讨论的“两段缓存即足够”或逐段永久提交约束。结果只代表本次输入与规则下的划分；追加笔或上游Bi重新选路后可重新计算，跨快照的永久确认、增量续读和冻结规则另定。

### 002.b — 算法概述

1. **先列候选，再查完成依据。** 对连续笔区间检查奇数笔、至少三笔、首三笔重叠、方向和端点价格关系；不合格只排除该区间。对合格区间，按假设分界保留第一特征序列；有缺口时继续检查第二特征序列。记录成功依据、相容限制或尚未确认状态，不用“反向三笔已出现”代替完整判定。
2. **从最早能形成已完成路线的位置开始。** 按P[0]、P[1]等依次寻找；只有基本形状而没有完成依据，不能据此固定起点。起点确定后，所有选中段必须从这里连通，不在中途另起路线。
3. **给完整工作状态准备记录。** memo029到同一分型只留一条最多笔数前缀；线段先研究以“末段起终点＋影响后继的特征／确认上下文”为状态q，记录best[q]与prev[q]。同一终点、甚至同一起终点的两种历史，若仍有不同后继限制，就不能只因其中段数较少而删除。具体状态字段及何时能够合并，见005的待定项。
4. **检查能否接入下一段。** 从每个可达状态尝试首尾相接、方向相反的候选，复核新段完成依据以及与已有前缀的相容性；普通失败继续尝试其他连接。只有已经证明未来合法接法相同的状态，才比较段数并保留最多者；候选依据未定或相容性未知时继续保留区别，不能擅自当作合法或不合法。
5. **选择终点并回溯。** 在全部合法完成状态中，选择几何终点最晚、同终点段数最多者，沿prev找回路线。再独立复核连续性、交替性、每段成员及完成依据，同时返回未覆盖范围与末尾候选。选路最优性须另作对照，不能仅凭逐段合法就声称最优。

这里复用的是“把后续行为相同的前缀合并”的DP思路，不是直接复用best[j]数组。002.c–f具体化已验收证据图上的选路；候选识别和图合同仍见005，图内最优不等于完整线段算法已验证。

### 002.c — Algorithm Tree

本节把memo029的“固定起点、逐状态取最大值、沿前驱回溯”用于线段选路。[10] **以下具体化选路层；识别层须先给出已验收的证据状态图G，不能把尚未定义的线段判定当作已解决。**

**图的合同。** 每个状态q保存候选段S(i,j)、完成证书及影响后继的上下文σ；证书含两类破坏所用特征元素、来源笔和证据水位。根状态允许作为首段；边p→q只允许首尾相接、方向相反且整个前缀的证据相容。σ须保留全部尚影响后继的分界／归属约束，同q的历史具有相同合法后继，包括尾部候选的相容性；不能仅因终点相同就合并。候选识别、图的完备性和此状态充分性是独立验收条件，见005。G另带未完成候选：tail[q]是与结束状态q相容的尾部列表，pending是无完成路线时保留的候选；二者不参与计分。

每次转移恰好接入一个已有完成证据的段，段数增加1；未完成候选不进入G。状态按(j,i,id)递增，前驱按相同顺序遍历；id是图内固定整数编号，不按价格或证据时间排序。best[q]为固定起点到q的最多段数，不可达记−1。

```text
证据状态图上的动态规划选线段
├── 2.1 验收输入与图合同
│   ├── 来源／图结构无效 → 报错停止
│   ├── 识别、证据相容或状态充分性尚未确定
│   │   → 返回“判定规范未完成”；不伪装为空路线
│   └── 已通过合同验收 → 转2.2
├── 2.2 找最早起点
│   → a=全部合法根状态中最小的i
│   ├── 没有根状态 → 返回空路线、全部未决范围及G.pending；正常结束
│   └── 有根状态 → 转2.3
├── 2.3 初始化
│   → 所有best=−1、prev=None；按固定顺序逐个处理q；转2.4
├── 2.4 检查当前q
│   ├── 全部处理完 → 转2.7
│   └── 尚有q
│       → 若q是起点a的根状态，置best[q]=1
│       → 逐个检查前驱p；转2.5
├── 2.5 尝试前驱p
│   ├── 当前q的前驱已检查完 → 处理下一个q；回2.4
│   ├── best[p]<1 → 略过p，检查下一个前驱；回2.5
│   └── best[p]≥1 → candidate=best[p]+1；转2.6
├── 2.6 比较段数
│   ├── candidate>best[q] → best[q]=candidate；prev[q]=p
│   └── candidate≤best[q] → 保留原记录
│   → 检查下一个前驱；回2.5
├── 2.7 选结束状态
│   → 在可达状态中，先取j最大、再取best最大者；仍同分取先处理者
│   ├── 不存在 → 内部状态错误［2.2已有合法根］
│   └── 存在end → 转2.8
├── 2.8 回溯
│   → 从end沿prev回到起点a的根状态，倒序得到路线
│   → 缺前驱、非图边或几何位置不递增，报内部状态错误；否则转2.9
└── 2.9 独立复核并返回
    → 核对路线连通／交替、每段成员及完成证据、全路线相容性、段数
    ├── 失败 → 报错，不输出为合法结果
    └── 通过 → 返回路线、证书、未覆盖范围及尾部候选；正常结束
```

若G仅是部分候选图，只能称“该图内最优”；只有识别和图完备性也通过独立验收，才能称满足002.a目标的线段选路结果。空图与“尚未会判定”是两种不同结果。

两组确认算术与四组给定状态图的选路核对见[核验记录](../../artifacts/mas/memo021-dp-details/root-recheck.json)；它们不证明识别或图完备性。

**边界与成本。** 普通候选／图边失败只略过当前连接；无完成段正常返回空结果。EOF不把尾部候选计入完成段。图已建立且顺序已给定时，选路O(|V|+|E|)、数组及前驱O(|V|)；排序、候选识别、证据、上下文与图生成及最终独立复核另计，不能据此声称整套算法O(N²)。

### 002.e — Helper Functions

以下是选路层契约，不新增领域类。识别层的证书生成及语义验收仍须按005补齐；这些职责不能用一个未经定义的布尔函数替代。

| 过程 | 必要职责 |
|---|---|
| _validate_graph(source,G) | 检查确切来源、唯一整数id、0≤i<j≤N、候选基本形状、证书来源及水位、根标记、边的共享端点／反向和拓扑顺序，以及tail／pending的来源范围。该结构检查不证明完成判定或候选完备性。 |
| _ordered(G) | 按(j,i,id)给出状态顺序；每个前驱列表按同序排列，不临时按段数重排。 |
| _find_start(G) | 返回合法根状态的最小i；无根返回None，不以未完成候选固定起点。 |
| _recover(prev,a,end,G) | 逐步核对前驱为真实图边，回到起点a的根状态后倒序；缺失／越界报错。 |
| _verify_selected(source,route,G) | 独立按001重查每段基本形状、第一／第二类完成证据及全路线相容性，不信任best缓存；失败报错，遇未定规则返回“判定规范未完成”。 |
| _unresolved(N,route) | 空路线返回笔范围[0,N)；否则返回非空的[0,first.i)、[last.j,N)。这些是未被已完成段覆盖的范围，可能已经用于确认。 |

### 002.f — Pseudocode

输入为固定笔快照与已验收的证据状态图，图合同见002.c；这是完整的选路层流程，尚不包含从笔生成G的完整识别器。

```text
select_segments(source,G):
    N ← 输入笔数
    若识别／相容／状态合同未确定：返回“判定规范未完成”
    _validate_graph(source,G)
    order ← _ordered(G)
    a ← _find_start(G)
    若a为None：
        返回空路线、全部未决范围及G.pending

    所有best ← −1；所有prev ← None
    对q依order遍历：
        若q是根且q.i=a：best[q] ← 1
        对p依固定顺序遍历G中q的前驱：
            若best[p]≥1且best[p]+1>best[q]：
                best[q] ← best[p]+1
                prev[q] ← p

    end ← None
    对q依order遍历：
        若best[q]<1：继续
        若end为空或(q.j,best[q])>(end.j,best[end])：end ← q
    若end为空：报内部状态错误

    route ← _recover(prev,a,end,G)
    evidence ← _verify_selected(source,route,G)
    若复核未定：返回“判定规范未完成”
    要求route首段.i=a、末段=end、len(route)=best[end]
    返回{route,evidence,optimality_scope="G内最优",
         unresolved=_unresolved(N,route),
         tail_candidates=G.tail[end]}
```

同一状态的最多前缀只用于合同所保证的等价上下文；不能把不同σ的状态强行共用一条prev。选中路线的合法性复核、图内选路最优性、识别及图完备性，是三项分别验收的结论。

## 003 — Reasoning (Why)

1. **形状与完成分开。** 初始三笔重叠是必要条件，不能保证已有合法结束依据。若把每个满足形状的区间当作一条合法边并最大化段数，可能把尚未确认的结构全部计入结果，从而改变001定义。[1–4]
2. **状态必须保留后继需要的信息。** memo029中单笔合法性只依赖端点和固定区间，因而可复用同端点的最多笔前缀。线段还涉及分界两侧的特征元素归属、包含处理和第二特征序列；在证明它们可由端点或固定证据独立重建前，不能直接采用相同的压缩。[1][2][4]
3. **DP成立的条件。** 固定起点后，若两条合法前缀在同一状态q下，对所有后续连接具有相同合法性，且接入相同完成段均增加1段，则较少段数的前缀可以舍弃。只允许在这些条件已证明的状态之间应用best[q]及前驱回溯；终点相同并不足以证明状态等价。
4. **成本边界。** N笔只有O(N²)个几何区间，但每个区间可能具有不同的证据及相容上下文；它们不能未经证明地压成一条边。因此当前不宣称线段DP为O(N²)、总状态为O(N)或只需两个缓存。实际复杂度须把候选生成、证据判定、状态数量和兼容转移一起计算。

### A.1 — 第67课：从特征序列到两类破坏的连续论述

出处：正文16–46行。[1] 保留从方向、序列、标准化到缺口分类及其逻辑顺序的整段；其中“娇注”是整理者评价，不是作者撤回或修改原定义的证据。

> 笔的划分标准在前面已经严格给出，因此，下一关键问题，就是如何划分线段。下面，给出类似笔划分，但有重大区别的划分标准。用S代表向上的笔，X代表向下的笔。那么所有的线段，无非两种：一、从向上笔开始；二、从向下笔开始。简单起见，以向上笔开始的线段为例子说划分的标准。
>
> 以向上笔开始的线段，可以用笔的序列表示：S1X1S2X2S3X3…SnXn。容易证明，任何Si与Si+1之间，一定有重合区间。而考察序列X1X2…Xn，该序列中， Xi与Xi+1之间并不一定有重合区间，因此，这序列更能代表线段的性质。
>
> **定义：序列X1X2…Xn成为以向上笔开始线段的特征序列；序列S1S2…Sn成为以向下笔开始线段的特征序列。特征序列两相邻元素间没有重合区间，称为该序列的一个缺口。**
>
> 关于特征序列，把每一元素看成是一K线，那么，如同一般K线图中找分型的方法，也存在所谓的包含关系，也可以对此进行非包含处理。经过非包含处理的特征序列，成为标准特征序列。以后没有特别说明，特征序列都是指标准特征序列。（娇注：这里的描述有欠缺，出现肯定论点后找论据的逻辑顺序错误。没有明确同一段前不能进行非包含处理。）
>
> 参照一般K线图关于顶分型与底分型的定义，可以确定特征序列的顶和底。注意，以向上笔开始的线段的特征序列，只考察顶分型；以向下笔开始的线段，只考察底分型。
>
> 在标准特征序列里，构成分型的三个相邻元素，只有两种可能：
>
> **第一种情况：**
>
> **特征序列的顶分型中，第一和第二元素间不存在特征序列的缺口，那么该线段在该顶分型的高点处结束，该高点是该线段的终点；特征序列的底分型中，第一和第二元素间不存在特征序列的缺口，那么该线段在该底分型的低点处结束，该低点是该线段的终点；**（娇注：这里描述不全面，后期有补充。）
>
> **第二种情况：**
>
> **特征序列的顶分型中，第一和第二元素间存在特征序列的缺口，如果从该分型最高点开始的向下一笔开始的序列的特征序列出现底分型，那么该线段在该顶分型的高点处结束，该高点是该线段的终点；特征序列的底分型中，第一和第二元素间存在特征序列的缺口，如果从该分型最低点开始的向上一笔开始的序列的特征序列出现顶分型，那么该线段在该底分型的低点处结束，该低点是该线段的终点；**
>
> （娇注：第二种情况属于第三线段成立倒推第二线段成立的判断）
>
> 强调，在第二种情况下，后一特征序列不一定封闭前一特征序列相应的缺口，而且，第二个序列中的分型，不分第一二种情况，只要有分型就可以。
>
> 上面两种情况，就给出所有线段划分的标准。显然，出现特征序列的分型，是线段结束的前提条件。本课，就是把前面“线段破坏的充要条件就是被另一个线段破坏”精确化了。因此，以后关于线段的划分，都以此精确的定义为基础。

### A.2 — 第71课：同一序列前提、假设转折点与两侧包含

出处：正文28–62行。[2] 连续保留特殊的第一笔破坏、三笔方向未定、假设分界、第一／第二元素的缺口，以及何处可以做包含的解释。末尾三张图均来自整理本紧邻正文的配图区，已查看：第一张是四种线段情形示意，后两张是指数分钟图；不能由这些回看标记推断实时确认时刻。

> 虽然67课已经给出了线段划分的标准，但由于那里用的是比较抽象的类数学语言，所以理解上可能还有困难，因此，逐一进行再分辨。
>
> 首先要分辨的，是特征序列中元素的包含关系。注意，特征序列的元素包含关系，首先的前提是这元素都在一特征序列里，如果两个不同的特征序列之间的元素，讨论包含关系是没意义的。
>
> 显然，特征序列的元素的方向，和其对应的段的方向是刚好相反的，例如，一个向上段后接着一个向下段，前者的特征序列元素是向下的，后者是向上的，因此，根本也不可能存在包含的可能。
>
> *那么，为什么可以定义特征序列的分型呢？因为在实际判断中，在前一段没有被笔破坏时，依然不能定义后特征序列的元素，这时候，当然可以存在前一特征序列的分型，这时候，由于还在同一特征序列中，因此，序列元素的包含关系是可以成立的；*
>
> **而当前一段被笔破坏时，显然，最早破坏的一笔如果不是转折点开始的第一笔，那么，特征序列的分型结构也能成立，因为在这种情况下，转折点前的最后一个特征序列元素与转折点后第一个特征元素之间肯定有缺口，而且后者与最早破坏那笔肯定不是包含关系，否则该缺口就不可能被封闭，破坏那笔也就不可能破坏前一线段的走势。这里的逻辑关系很明确的，线段要被笔破坏，那么必须其最后一个特征序列的缺口被封闭，否则就不存在被笔破坏的情况。**
>
> **那么，现在只剩下最后一种情况，就是最早破坏那笔就是转折点下来的第一笔，这种情况下，这一笔，如果后面延伸出成为线段的走势，那么这一笔就属于中间地带，既不能说是前面一段的特征序列，更不能说是后一段的特征序列，在这里情况下，即使出现似乎有特征序列的包含关系的走势，也不能算，因为，这一笔不是严格地属于前一段的特征序列，属于待定状态，一旦该笔延伸出三笔以上，那么新的线段就形成了，那时候谈论前一线段特征序列的包含关系就没意义了。**
>
> **总之，上面说得很复杂，其实就是一句话，特征序列的元素要探讨包含关系，首先必须是同一特征序列的元素，这在理论上十分明确的。**
>
> 从上面的分析就可以知道，从转折点开始，如果第一笔就破坏了前线段，进而该笔延伸出三笔来，其中第三笔破点第一笔的结束位置，那么，新的线段一定形成，前线段一定结束。
>
> 这种情况还有更复杂一点的情况，就是第三笔完全在第一笔的范围内，这样，这三笔就分不出是向上还是向下，这样也就定义不了什么特征序列，为什么？因为特征序列是和走势相反的，而走势连方向都没有，那怎么知道哪个元素属于特征序列？这种情况，无非两种最后的结果：1、最终还是先破了第一笔的结束位置，这时候，新的线段显然成立，旧线段还是被破坏了；2、最终，先破第一笔的开始位置，这样，旧线段只被一笔破坏，接着就延续原来的方向，那么，显然旧线段依然延续，新线段没有出现。
>
> 在67课里，把线段的划分分为两种情况，显然，分清楚是哪种情况，对划分线段十分关键**。其实，在那里已经把问题说得很清楚，判断的标准只有一个，就是特征序列的分型中，第一和第二元素间存不存在特征序列的缺口。**从上面的分析可以知道，这个分型结构中所谓特征序列的元素，**其实是站在假设旧线段没被破坏的角度说的**，而就像所有的分型一样，就算是一般K线的，都是前后两段走势的分水岭、连接点。这和包含的情况不同，包含的关系是对同一段说的，而分型，必然是属于前后的，这时候，在构成分型的元素里，如果线段被最终破坏，那后面的元素肯定不是特征序列里的，也就是说，这时候，分型右侧的元素肯定不属于前后任何一段的特征序列。
>
> 这个道理其实很明白，例如前一段是向上的，那么特征序列元素是向下的，而在顶分型的右侧元素，如果最终真满足破坏前线段的要求，那么后线段的方向就是向下的，其特征序列就是向上的，而顶分型的右侧元素是向下的，显然不属于后一段的特征元素，而该顶分型的右侧元素又属于后一段，那么显然更不是前一段的特征元素。**所以，对于顶分型的右侧特征元素，只是一般判断方面的一种方便的预设，就如同几何里面，添加辅助线去证明问题一样，辅助线不属于图形本身，就如同顶分型的右侧特征元素其实不一定属于任何的特征元素，但对研究有帮助，当然是要大力去用的，如此而已。**
>
> **其实，线段的划分，都是可以当下完成的，无非是如下的程序：假设某转折点是两线段的分界点，然后对此用线段划分的两种情况去考察是否满足，如果满足其中一种，那么这点就是真正的线段的分界点；如果不满足，那就不是，原来的线段依然延续，就这么简单。**
>
> **特征序列的分型中，第一元素就是以该假设转折点前线段的最后一个特征元素，第二个元素，就是从这转折点开始的第一笔，显然，这两者之间是同方向的，因此，如果这两者之间有缺口，那么就是第二种情况，否则就是第一种，然后根据定义来考察就可以。**
>
> **这里还要强调一下包含的问题，上面的分析知道，在这假设的转折点前后那两元素，是不存在包含关系的**。因为，这两者已经被假设不是同一性质的东西，不一定是同一特征序列的；但假设的转折点后的顶分型的元素，是可以应用包含关系的。为什么？因此，这些元素间，肯定是同一性质的东西，或者就是原线段的延续，那么就同是原线段的特征序列中，或者就是新线段的非特征序列中，反正都是同一类的东西，同一类的东西，当然可以考察包含关系。

### A.3 — 第77课：至少三笔、首三笔重合与反向线段破坏

出处：正文73–99行。[3] 保留后继线段确认、第二特征序列不再递归分类的理由与80–83实例。该论证里的“线段A／B／C”在破坏关系确认前只是暂称，不能删除这项限定。

> 有了笔以后，就是线段了。线段划分的最基本原则，就是线段必须至少有三笔，这是十分显然的，否则，一笔都能构成线段，那笔和线段又有什么区别？至于两笔为什么不能构成线段，这理由更简单，因为两笔，那么线段的两段的分型的性质肯定是一样的，和笔一样，一个完整线段的两段的分型不可能是同性质的。也就是说，和笔一样，线段也不可能从一个顶开始结束于一个顶，或者从一个底开始结束于一个底。由此可见，线段中包含笔的数目，都是单数的。
>
> 而且，线段开始的那三笔，必须有重合，开始三笔没有重合的，是构不成线段的。
>
> 另外，线段必须被线段所破坏才能确定其完成。对于线段划分的第一种情况，如果第一笔出现笔破坏后，接着的一笔就创新高，而且再后一笔，根本就不触及笔破坏那一笔，那么，这时候，显然构成不了线段对线段的破坏，因为后面这这三笔没有重合，不可能构成一线段。
>
> 而这，用第一种情况的判断法就更明确了，上面这种情况根本不可能形成特征序列的分型，当然就不可能是线段的完成。
>
> 再者，线段被线段破坏，必须不能是被同一性质的线段所破坏，也就是从向上一笔开始的线段不可能被向上一笔的线段所有破坏，必然是被从向下一笔开始的线段所破坏。
>
> 线段的第二种情况，其实就包含这种情况。也就是，按第一种情况，线段A没有被接着的线段B破坏，但接着的线段C破坏了线段B，因此，线段B是完成的，当然线段A也应该是完成的。注意，这里的线段A、B、C只是用结合律的原则先划分，括弧里面满足线段的基本性质，在这破坏关系没被确认之前，这只是一个假设的称呼。
>
> 各位肯定注意，在第二种情况下特别强调，第二特征序列，其实就是对应着线段C对线段B的破坏，不再分第一、二种情况了。这，其实是一个简化的方法。为什么？
>
> 如果我们坚持线段的最终破坏回补特征序列缺口情况，那么，如果线段C对线段B还是第二种情况，那么线段C的区间肯定就在线段A特征序列缺口与线段B特征序列缺口之间，如此类推，总会出现一个线段X，使得对应前面的线段是回补特征序列缺口，否则，这些线段的区间就会无限缩小，最后就会形成一个点，这显然是不可能的，学过极限的都应该能理解。所以，在一串的相对前一线段是第二种情况的线段串中，比如最终会出现第一种情况的破坏，这样倒推回来，必然有这一串假定线段间的连续破坏。
>
> 正因为这样，所以在第二种情况中的第二特征序列判断中，就不再分第一、二种情况了，这样是免得有一串线段串不断收敛后倒推回来的麻烦。这在数学上当然是绝对完美，但操作起来太麻烦，而且这种特殊的情况很少见，就更没必要了。
>
> 那么，为什么要区分第二种情况，因为是不希望在线段的层次上出现小级别转大级别这样不确定的情况，用第二种情况就能解决这个问题。
>
> 有一种复杂的情况，在今天的80-83的划分中就出现了。就是对80-81，出现了第一笔的笔破坏，然后接着是一个符合线段标准的走势A，但没有创新低，这样当然不能算是原线段的延续，但线段的破坏也不能算，为什么？因为没有符合要求的三笔。接着，一个反弹，也满足线段的要求，然后就转头继续创新低。这里有一个细微的区别，如果这个反弹只是一笔，那么就没有破坏走势A，后面接着的新底，就意味着走势A依然延续，所以走势A就是原来80-81的延续。
>
> 但现在的问题是，这个反弹把走势A给线段破坏了，因此，说走势A依然延续是显然不对的，所以后面的走势和走势A无关，因此，唯一合理的划分，就是把第一笔的笔破坏、走势A、一个反弹合成一个线段，这完全满足线段的定义，所以就有了81-82。
>

> 线段的划分，其实一点都不难，关键是要从定义出发。而且用线段划分的两种情况的规定，不难证明，线段的划分也是唯一的。

### A.4 — 第78课：笔破坏失败、延续与标准化的适用范围

出处：正文28–74行。[4] 此段与第71课衔接，特别保留62行“线段B已经确认破坏前段”的前提，以及第二特征序列必须严格包含处理的说明。两张图含“娇注”或整理者构造解释；最后的标准化仅指把线段作为无内部结构部件用于后续分析，不是抹掉原线段来源或任意改端点。

> 线段的划分，就是上面课程里的两种情况，根据这两种情况的完全分类来，没有不能唯一去划分的。但一到实际划分，很多人就晕，为什么？因为基本的概念还是没搞清楚。
>
> 首先，线段和笔，都是有方向的，从顶开始的笔一定结束在底，同样，以向上笔开始的线段一定结束于向上笔，不可能一个线段，开始是向上笔，结束于一个向下笔。由于向上的笔的开始分型是底，而向下笔的结束分型也是底，换言之，一个线段，不可能是从底到底或从顶到顶，这是一个最基本的概念。
>
> 同样，正如同一笔不可能出现顶低于底的情况，同一线段中，两端的一顶一底，顶肯定要高于底，如果你划出一个不符合这基本要求的线段，那肯定是划错了。
>
> 由于图形不断延续，因此，除非是新股上市后最开始的一段，否则任何一段都是破坏前一段的，如果你的划分，不能保证前面每一段都是被后一段破坏，那么这划分肯定不对。线段的破坏是可以逆时间传递的，也就是说被后线段破坏的线段，一定破坏前线段，如果违反这个原则，那线段的划分一定有问题。
>
> 当然，实际划分中没必要都从上市第一天开始，一般都是从图K线中近期的最高或最低点开始，例如，如果你今天才开始进行划分1分钟图，那么，就可以从昨天下午跳水的最低点5224点开始，但这样，肯定对大的走势不可能有正确认识，要对这波行情有明确的分析，即使不从7月6日的3563点开始，也要从8月17日的4646点开始。
>
> 选择好了开始点，就可以进行分段了。如果熟练了，就可以直接分段，因为分型、笔都可以心算就知道，直接就可以进行分段；但如果不熟练，还是先从分型开始，然后笔，再线段，这样比较稳妥。
>
> 在实际划分中，会碰到一些古怪的线段。其实，所谓的古怪，是一点都不古怪，只是一般人心里有一个印象，觉得线段都是一波比一波高或低，很简单那种，其实，线段完全不必要这样。一般来说，在类似单边的走势中，线段都很简单，不会有太复杂的情况，而在震荡中，线段出现所谓古怪的可能性就大增了。
>
> 所有古怪的线段，都是因为线段出现第一种情况的笔破坏后最终没有在该方向由该笔发展形成线段破坏所造成的，这是线段古怪的唯一原因。因为，如果线段能在该方向出现被线段破坏，那就很正常了，没什么古怪的。
>

> 由最简单概念知道，任何线段都有方向的，例如线段B，其方向是下，也就是由向下笔开始的线段，那么其结束笔肯定也是向下笔。因此，线段出现第一种情况的笔破坏，这破坏的一笔肯定是向上笔，但这一笔之后，没有形成特征序列的分型，满足不了第一种线段破坏的情况，因此，就在这个方向上形成不了线段的破坏。

> 这个向下的线段，如果没破该向上笔的底，那么就可以肯定，由这向上的笔可以延伸出一个线段来，这时候，线段B肯定被破坏了。
>
> 注意，这个例子中有一个最关键的前提，就是线段B已经确认线段破坏了他前面的线段，如果线段B对前面线段的破坏都没确认，那就先确认，这里的分析都不适用了。
>
> 从这个例子就知道，笔破坏与线段破坏的异同。对于线段破坏的第二种情况，例如线段B对线段A是第二种情况，而线段C没有形成第二特征序列的分型又直接新高或新低了，这时候，不能认为这是三个线段，线段A、B、C加起来只能算是一个线段。
>
> 另外，一定要注意，对于第二种情况的第二特征序列的分型判断，必须严格按照包含关系的处理来，这里不存在第一种情况中的假设分界点两边不能进行包含关系处理的要求。为什么？因为在第一种情况中，如果分界点两边出现特征序列的包含关系，那证明对原线段转折的力度特别大，那当然不能用包含关系破坏这种力度的呈现。而在第二种情况的第二特征序列中，其方向是和原线段一致，包含关系的出现，就意味着原线段的能量充足，而第二种情况，本来就意味着对原线段转折的能量不足，这样一来，当然就必须按照包含关系来。
>
> 通过上面的讲解，应该没有任何线段问题能难倒各位了，当然前提是能把上面的内容搞明白。
>
> 注意，这里必须提醒一句，就是这在以前也曾说过，就是，如果线段中，最高或最低点不是线段的端点，那么，在任何以线段为基础的分析中，例如把线段为基础构成最小级别的中枢等，都可以把该线段标准化为最高低点都在端点。因为，在以线段为基础的分析中，都把线段当成一个没有内部结构的基本部件，所以，只需要关心这线段的实际区间就可以，这样就可以只看其高低点。
>
> 经过标准化处理后，所有向上线段都是以最低点开始最高点结束，向下线段都是以最高点开始最低点结束，这样，所以线段的连接，就形成一条延续不断、首尾相连的折线，这样，复杂的图形，就会十分地标准化，也为后面的中枢、走势类型等分析提供了最标准且基础的部件。

### A.5 — 第83课：线段作为最小中枢部件及两类破坏的心理解释

出处：作者正文19–37行，连续保留“为什么不用笔直接构造最小中枢”、偶然因素与确认、两类破坏的不同反攻过程。[5] 此段是作者的结构选择与心理解释，不是新增价格判据；其中“(注：非绝对）”是未署名整理注。原文第25行“需要三个特征序列分型”的措辞照录，不能擅自转成“每次结束都必须等三个完整分型”的可执行常量；几何判定仍须回到第67/71/77/78课前提。所引正文没有相应嵌图，后面的083/image001属于另一日解盘，不移作本段理论图。

> 一个最简单的问题，为什么不能由笔构成最小中枢？其实，这不是一个问题。为什么？因为实质上，我们是可以设计这样的程序，也就是用笔当成构成最小中枢的零件，但这样构造出来的系统，其稳定性极差。
>
> 众所周知，一笔的基础是顶和底分型，而一些瞬间的交易，就足以影响其结构。例如，突然有人打错单，或者有人给老鼠仓送货，那么全天走势的分析就大变样了。而由线段构成最小中枢，则不存在这个问题。为什么？一个线段的改变，不会因为一个偶尔一笔的错误而改变，也就是说，线段受偶尔性的影响比较少，想想要破坏一个线段的麻烦程度，就知道这一点。
>
> 从心理上看，偶尔因素是允许发生的，只要不被再次确认，就证明偶尔因素对原来的心理合力没有大影响，反过来确认了该合力的有效性。所以，线段破坏本身，其实就反应着一种微妙的心理结构的变化。特征序列分型的引入，本质上就是去勾勒这种心理结构的变化的。就像一般的分型，三次的确认才能构成，特征序列的分型，本质上也是一样的，这样的确认，其有效性就极大增加了。由此构成最小中枢的零件，才是合适的。
>
> 如果说三个K线的折腾就可以决定一笔的转折，那么一个线段的破坏转折，就需要三个特征序列分型的折腾，这样，市场买卖双方都有足够的时间去反应，从而使得体现出的合力痕迹，当然具有了一定的延续性。而一个线段，至少由三笔组成，这也使得转折后的新线段，同样可以让合力得到充分体现，而对比这两个不同方向的线段，买卖双方在相应时间内的心理、实力对比，就一目了然了。
>
> 更重要的是，线段破坏的两种方式，是有着很大的心理面不同的。第一种方式，第一笔攻击就直接攻破上一段的最后一次打击，证明这反攻的力量是有力的，再回来一笔，代表着原方向力量的再次打击，但反攻力量抗住并再次反攻形成特征序列的分型，这证明，这反攻至少构造了一个停歇的机会。最坏的情况，就是双方都稍微冷静一下，去选择再次的方向。而这，就恰好构成了最小中枢形成的心理基础。
>
> **中枢，其实就是买卖双方反复较量的过程，中枢越简单，证明其中一方的力量越强大**。**中枢的复杂程度，是考察市场最终动向的一个很重要的依据。一个超复杂的中枢过后，就算一方赢了，其后的走势也是经常反复不断的。**(注：非绝对）
>
> 而且，在同一趋势中，相邻两中枢的复杂程度、形态，经常有所区别。为什么？人都有提前量，而提前量，经常就是找最近的模本去抄袭，这样，等于在买卖的合力中，都加了一个提前的变量，从而造成整个结构的变化。这是一个很重要的原理，所谓不会二次跨进同一条河流，这本质上由人的贪嗔痴疑慢造成的。
>
> 至于线段的第二种破坏方式，本质上是以时间换空间，反攻开始的力量很弱，需要慢慢积累，这一方面代表原方向的力量很强，另一方面，又要密切关注是否会形成骨牌效应，也就是开始的反攻力量很小，却能迅速蔓延开，这往往证明，市场原方向的分力，其结构具有趋同性，一旦有点风吹草动，就集体转向。**这在投机性品种经常能看到，经常是一个小M头就引发大跳水。**趋同性，如果对于一般性品种来说，往往意味着庄家控盘程度高。
>
> **一些猛烈上涨或下跌的股票，往往甚至由于一个1分钟的小顶分型就引发大跳水或大反弹，其原因，就是这种分力的趋同性所引发的骨牌效应。一般来说，这种第二类的线段破坏，一旦出现骨牌效应，至少要回到前一高、低点范围内，这就是市场上冲顶和赶底时发生的V字型走势。**
>
> **分力的趋同性所引发的骨牌效应，基本上就是表现为所谓的多杀多、空杀空。特别在一些大的趋势之后，市场的力量一边倒，如果这时候突然来一个加速，一旦逆转，就会发生典型的多杀多、空杀空现象。**

## Appendix B — Notes from CC's implementation

### B.1 — 版本、入口和输入边界

本附录按实际CC本地仓库的只读快照分析：Git HEAD `374268381a3eaeee4d220e67d63364b3907405f4`，2026-11-09采集时工作区干净；逐文件SHA-256见清单。[7] 这不是较早网站快照 `b1348795…`，也不是TDS已采用的算法。完整执行语句保存在引用文件中；本轮只静态阅读和手工推演，没有导入或执行CC算法。

`build_xianduans()` 在少于三笔时返回空；否则规范化配置，建立一次性的 `_XianduanBuilder`，调用 `run()` 后由 `_finish()`生成对象（xianduan.py247–275行）。输入是已派生的 `Bi` 序列，笔的合法性、先后和方向交替主要由上游保证，不能把这个入口当作任意损坏笔序列的全面校验器。[8]

当前默认线段策略是standard／`LINE_ONLY`，非标准修复与震荡开关为OFF；`strong_bi`单笔成段是可选项目变体，不是第77课“至少三笔”的原文规则（config.py173–182行；xianduan.py733–763、917–930行）。`nonstandard`／`oscillation`虽传入构建器，当前初始化中保存标志、并不等于已执行全部注释所说的补齐或震荡算法；尤其oscillation明确标为TODO。[8][9]

### B.2 — 特征元素怎样生成候选

1. `_first_xianduan()`从左到右尝试起点，要求本向候选及其后的反向候选都能产生，才选定首段；此前可有暖机空白。找不到这对候选时，`_emit()`退回整窗一条forming示意，而不是保证全窗已有正式段（946–961、997–1046行）。
2. `_candidate(begin,direction)`只把反向笔送给 `_EigenFX`。每个 `_Eigen`保存高、低与其全部来源笔下标；第二元素调用`exclude_included=True`，新笔包住旧元素时可另立元素；第三元素允许合并并有相等边界特例。合并按候选段方向取高高或低低，不应与原始K线包含处理的适用场景混为一谈（281–332、374–422行）。
3. `_actual_break()`对第一特征序列使用中间元素的末个原始笔判突破，必要时查看第三元素之后的第2笔，依赖位置可能晚于几何端点。第二特征序列`GAP_REVERT`改用合并后元素的边界严格比较，且不前看。这是实际代码的两种角色，不能仅凭同名“分型”认定条件完全相同（424–456行）。
4. 顶分型比较为`e0.high < e1.high`、`e2.high <= e1.high`、`e2.low < e1.low`；底分型为`e2.high > e1.high`、`e0.low > e1.low`、`e2.low >= e1.low`。`_mark_gap()`以上升段`e0.high < e1.low`／下降段`e0.low > e1.high`作严格缺口判断，边界相等无缺口（458–477行）。这里包含非严格的一边，是CC实现口径，不把它重写成作者原句。[8]
5. 中间特征元素内的极值笔之前一笔是候选几何终点；候选至少三笔，并通过起终极值检查，才能输出。非候选则滑动／重建特征窗口继续扫描。候选带`rule`、`dep`，仍未冻结（479–507、663–693行）。

### B.3 — 候选成立之后，何时冻结、延伸或撤销

状态机维护已冻结历史、准完成`N0`与反向待确认`N1`。它是CC的动态冻结纪律，不能把N0出现就写成第67课意义之外的全部工程确认已完成（126–244、544–661行）。[8]

- 没有N0时，首候选晋升soft N0；反向候选出现后成为pending N1。原方向若又出现严格新极值且起点仍合法，会先延伸N0，不急于冻结。若反向未成段、延伸区曾越过旧起点，代码还可能走`pen_break_absorb`吸收失败笔破坏；这是带规则标签的CC分支，不能省成“只要破起点就换段”。
- 有N0和N1时，`_advance_n0n1()`先查N1能否延伸，再尝试N2。N2若已构成合法候选，冻结N0，N1升为新N0，N2成为新N1。没有N2时，必须同时有“严格破N1起点”和“后来回到N1方向创越其终点”的双证据，才作废N1并延伸N0；只见起点被破还要给N2成长机会（820–888行）。
- 若该延伸会破坏N0起点极值条件，走`rollover`：冻结旧N0、将N1升为新N0，避免把真反向吞掉。`_gate_ok()`冻结时检查笔数为奇数、至少三笔、首尾同向、首三笔闭区间重合与端点极值；`pen_break_absorb`豁免端点极值硬闸，`strong_bi`另有变体豁免（902–993行）。
- 缺口候选的额外反向证据由`_revert_confirm()`从端点后第2笔建立第二特征序列取得。若完整N2尚未形成，且证据早于／不晚于首个破坏，`gap_revert`可原子冻结前驱N0和缺口N1，并以该第二序列中间峰值建立下一soft候选；新候选不会仅因同一证据立即再冻结。第二序列只需反向分型，不递归套另一套“第二种”（220–244、632–657、765–791、881–886行）。

`_emit()`把冻结历史、soft N0、pending N1分别输出；右侧未确认部分按同向真实极值画forming。`_finish()`从来源笔聚合实际high／low、起止价格、来源时间和合并下标，写入规则、依赖和冻结标签。几何终点、读到的证据位置与冻结时刻不能互换：尤其普通N2冻结分支保留原候选`dep`，并未自动补填独立`confirmation_ts`；明确记录该时间的主要是gap_revert分支（997–1148行）。这限制了从普通对象trace重建完整确认事件时间线的能力。[8]

### B.5 — 同组输入的边界对照与仍需验证的部分

- **相等不是严格击破。** pending下段N1起点关键价22，后来的high=22不触发`is_n1_broken`；22.1才满足`>22`。但严格破坏本身仍不能跳过B.3所述N2／双证据裁决。这是辅助条件演示，不声称从一个数值就得到完整段输出。
- **缺口替代分支。** 另取六笔端点`10,18,14,24,19,22,16`，特征区间为[14,18]、[19,24]、[16,22]，顶形与实际突破成立，18<19有缺口，产生`rule=gap`候选，其几何终点在B2。只有这六笔并不能取得足够反向证据，也不能冻结。若把中间低点改为18，则18<18为假，只说明缺口标志改变；后续确认仍须继续处理，而不是其他规则一概豁免。
- **包含与第二序列不能省略。** 第三特征元素落入中间元素时会合并并等待更多输入；`GAP_REVERT`的严格比较使用合并后边界，不能用末个原始笔或PRIMARY前看偷换。当前只给出了可核对的主序列、相等／缺口补充；复杂的包含、失败吸收、原子缺口冻结和全部变体尚未运行覆盖。
- **复杂度与稳定性。** 入口每次重新构造状态，并非跨调用增量引擎；`_first_xianduan`逐起点重扫、候选查找／滑窗重放／极值检查都有嵌套扫描，不能宣称整层严格O(n)。冻结区“不回改”是一次状态机在正常后续生长下的工程约束；替换上游笔、改变历史或配置后重新调用，不应保证输出仍相同。原文定义、CC项目豁免与TDS未来算法仍须分别评议。


### B.6 — 二次核对：包含的分支表、输出变换与显示层边界

`_Eigen.test_combine()`（300–321行）按以下顺序短路；不能只笼统写“包含都合并”。[8]

| 顺序 | 实际条件与返回 | 适用位置 |
|---|---|---|
| 1 | 旧元素包住新笔（含完全相等）直接`combine` | 第二／第三元素均如此，先于其他特例 |
| 2 | 新笔包住旧元素，且`allow_top_equal=1`、顶相等而low下降，返回`down`；对称的底相等/high上升返回`up` | 第三元素可用，第二元素传`None`没有此特例 |
| 3 | 其余“新包旧”：`exclude_included=True`返回`included`，否则`combine` | 第二元素保留分界，第三元素通常合并 |
| 4 | 无包含时比较高低方向，返回`down/up` | 仍需后续分型与实际突破检查 |

`_reset()`（479–487行）不是只丢掉一个矩形，而是取已喂反向笔`lst[1:]`，清空三个元素后逐笔重放；因此包含后的来源成员、滑窗次数及依赖位置都须按原始笔追踪。此处也不能凭“一次右移”就宣称恒定代价。

**可选strong_bi链条。** `_try_strong_bi_break()`（733–763行）只考虑前候选结束后的第一根反向笔，必须严格破前段起点，且紧接该单笔之后能从`single+1`形成反向标准段，才返回单笔候选；依赖取该标准段水位。主循环仍让它进入N1/N2裁决，而不是单笔破位立即冻结；成为strong N0后不再延伸／失败吸收，本会作废N1并延伸N0的场景改走rollover保持该单笔几何（544–659、820–888、917–930行）。这是项目变体，不是原文“至少三笔”的例外定理。

**输出和候选并非逐字段原样透传。** `_emit()`（997–1046行）把pending N1的公开`rule_kind`改成`forming`，并按`_forming_end()`选择同方向极值笔；这个形成中展示终点可能晚于原候选终点，`dep_index`仍来自原N1。几何成员水位与依赖字段因此要分别读；不能从公开forming对象反推出其内部曾是gap候选。无候选的整窗forming／尾部forming只是展示兜底，不经过冻结硬闸。`_forming_end()`用Python的`max/min`，同价时取遍历中首个极值，而非凭注释“最新”强制改成最后同价位置（1048–1056行）。

`_finish()`（1095–1137行）对全部几何成员求high/low，但来源时间两端与合并下标仅从首／末成员trace取值，缺trace时回退对应端点时间；`dep_to_index`是笔依赖位置，不是原始K线下标。正常输入下这可组成包络，函数没有另行审计所有成员的trace是否一致／完备。主循环还设`guard<4*n`防御上界，到上界后返回当前状态，不提供额外的收敛证明或终止错误报告。

**三个显示类别。** `build_feature_sequence_overlays()`（1248–1353行）另行构建显示结果：PRIMARY画每段反向笔合并元素；SECOND仅为frozen gap段重现`GAP_REVERT`确认序列，编号按每个事件重新从0开始；TAIL_PROBE画假想后段的同向临时探测，不参与确认。PRIMARY的`_feature_elements()`不运行exclude／前看／分型判定，故图上的矩形不是候选识别器三个工作元素的逐状态镜像（1220–1245行）。

此外，该显示入口创建`_XianduanBuilder`时只转发nonstandard/oscillation，未像`build_xianduans()`267–271行转发strong_bi。因此“同cfg即同分段”的注释不能无条件推广到可选STRONG_BI配置；默认standard不触发此差别。本次只记录可执行参数转发差异，未运行比较或改动源码。
