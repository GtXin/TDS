## 003 — Implemented Kline family interface
### 003.a — Kline and KlineTSeries
`Kline` stores nine immutable fields: `symbol`, `period`, `source`, `timestamp`, `open`, `high`, `low`, `close` and `volume`. `KlineTSeries.klines` is an immutable tuple of bars; construction copies an input iterable and validates immediately.

| Method or operation | Behavior |
| --- | --- |
| `Kline(symbol, period, source, timestamp, open, high, low, close, volume)` | Construct one bar and automatically validate it. |
| `bar.validate()` | Check nonblank provenance, aware UTC datetime, finite OHLCV, price bounds and nonnegative volume. Accept float/int values except bool; integers must be exactly representable as float. |
| `KlineTSeries(klines)` | Materialize a nonempty iterable of Kline objects into a tuple and automatically validate it. |
| `series.validate()` | Check every bar, one symbol/period and strictly increasing timestamps. Mixed sources are allowed. |
| `len(series)` | Number of bars. |
| `series[index]` | One Kline; negative indexing follows Python behavior. |
| `series[start:stop:step]` | A tuple of bars, including an empty tuple when the slice has no matches. |
| `iter(series)` | Iterate over bars in stored order. |

Invalid construction or validation raises `ValueError`; invalid indexing follows normal Python exceptions. These classes contain no file I/O.
### 003.b — CSV functions
Import file functions from `chanlab.data.kline_csv`; they are separate from the domain classes.

| Function | Behavior |
| --- | --- |
| `read_kline_csv(path, context_path=None)` | Read the exact nine-column raw schema or existing 41-column master header. Return `(KlineTSeries, immutable_context_mapping)`; absent context returns an empty mapping. |
| `write_kline_csv(series, path, context_path=None, *, context=None)` | Validate and write nine raw columns plus an optional `key,value` context file. Nonempty context requires `context_path`; data and context must refer to different files. Existing output files are replaced. |

Raw output columns, in order: `timestamp,symbol,period,source,open,high,low,close,volume`. Reading the master projects only these raw fields; exporting does not recreate its feature columns. Numeric values, UTC instants and provenance are retained, while ISO/float spelling may normalize. Read validation errors identify the file, row and field. ChanTable object-conversion methods and DataFrame conversion remain deferred. The planned `series.plot()` extension is specified in the Appendix and is not part of the implemented interface above.
### 003.c — Runnable example
Run from the repository root using `.venv/bin/python` with `PYTHONPATH=src`:
```python
from datetime import UTC, datetime
from pathlib import Path
from tempfile import TemporaryDirectory

from chanlab.algo.kline import Kline, KlineTSeries
from chanlab.data.kline_csv import read_kline_csv, write_kline_csv

bar = Kline("EXAMPLE", "15m", "manual", datetime(2026, 1, 1, tzinfo=UTC),
            11.0, 13.0, 10.0, 12.0, 20.0)
single = KlineTSeries([bar])
assert single[0] is bar
assert single[:] == (bar,)

folder = Path("samples/chan_table")
series, context = read_kline_csv(
    next(folder.glob("*chan_table*.csv")), next(folder.glob("*context*.csv"))
)
assert len(series) == 10060
with TemporaryDirectory() as directory:
    output = Path(directory)
    write_kline_csv(series, output / "raw.csv", output / "context.csv", context=context)
    restored, restored_context = read_kline_csv(output / "raw.csv", output / "context.csv")
    assert restored.klines == series.klines
    assert restored_context == context
```
## Appendix — Plotly plotting
**Status:** Plotly is the selected backend. The following interface and example are planned; the current code does not yet provide `plot()`.

1. **Purpose.** Use Plotly's candlestick trace for OHLC bars and interactive inspection.[4] Our helper supplies Kline data, labels and future Chan overlays; Plotly handles rendering.
2. **Interface.** Add `series.plot(*, start=None, stop=None, volume=True, title=None) -> plotly.graph_objects.Figure`. `start`/`stop` use Python slice positions; both omitted means the full series. Reject an empty selection. Return the figure without opening a browser or writing files automatically.
3. **Code boundary.** The method delegates to `plot_kline_series(...)` in proposed `src/chanlab/visualization/kline_plot.py`. Import the helper/Plotly only when plotting is called. Keep OHLCV validation and Chan algorithms independent of rendering; a DataFrame is not required.
4. **Chart.** Draw UTC timestamps against OHLC candles; when `volume=True`, add volume bars below with a shared time axis using `make_subplots`.[5] Label symbol, period, UTC and source-defined volume units. Preserve session gaps and input values; do not resample or silently discard bars. Request a smaller slice for detailed inspection.
5. **Dependency.** During implementation, add Plotly as an optional `plot` extra and lock it with uv: `uv add --optional plot plotly`. Plotting must give a clear installation message when the extra is absent; raw classes and CSV I/O must still work. This documentation update does not install the package.
6. **Display/export.** The caller chooses `fig.show()` or `fig.write_html(...)`. Save generated charts under `artifacts/`; `include_plotlyjs=True` embeds the renderer for a standalone HTML file.[6] Website embedding and Chan feature overlays are later extensions.
7. **Acceptance.** Compare each plotted timestamp/OHLC/volume value with the selected source bars. Check full/sliced input, volume on/off, empty selection, missing optional dependency, unchanged source objects and HTML export. Visually inspect one representative chart. The earlier165-test/93%-coverage result covers raw classes/CSV only, not this pending extension.

Planned usage after implementation, with `series` loaded as in003.c:
```python
from pathlib import Path

fig = series.plot(start=-200, volume=True)
fig.show()
output = Path("artifacts/kline/cc_last200.html")
output.parent.mkdir(parents=True, exist_ok=True)
fig.write_html(output, include_plotlyjs=True)
```
