# Skill — Algorithm Development

## 000 — Scope

记录算法开发Skill候选，重点关注缠论算法中的前提错误、推理检查与边界遗漏。以下为已有GitHub调研摘要；候选尚未安装或试运行，不代表已验证效果。

## 001 — 候选比较

| Skill | 主要用途 | 缠论开发中的位置 |
|---|---|---|
| computer-scientist [1] | 问题建模、假设、不变量、正确性与复杂度 | 算法设计的总体检查 |
| invariant-guard [2] | 编码前明确契约、循环不变量、终止依据及边界条件 | 先审查规则前提与推理 |
| algorithm-design [3] | 明确输入输出、伪代码与图示 | 整理可执行的算法说明 |
| proptest-praxis [4] | 对照独立模型、生成操作序列、缩减失败反例 | 实现后的性质测试与边界验证 |

## 002 — 建议与当前状态

1. 优先进一步检查 `invariant-guard`，评估其能否帮助明确前提、保持不变量并检查边界；这只是候选建议，尚未决定采用。
2. 有实现后再评估 `proptest-praxis`，用独立模型和最小反例检查结果；测试通过不等于正确性证明。
