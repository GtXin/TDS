### 001.a — Implement the MergedKline family
1. **Set the interface contract.** Use the complete member/method inventory in003, including trace, explanation and plotting. Resolve the open contracts in the Appendix before implementing dependent interfaces; retain explicitly deferred integrations in the inventory rather than silently dropping them.
2. **Implement the immutable record.** Store memo009’s eight fields and validate automatically. Keep local record checks separate from owning-series checks against the exact raw source. Integer IDs are result-scoped; `MK12` is a display label, not a stored ID or source index.
3. **Implement the immutable series.** Retain the original `KlineTSeries` object, ordered record tuple, immutable configuration, versioned rule reference, full trace and per-record trace indices. Add sequence operations, ID lookup and validation with the behavior in003.a.
4. **Implement memo015’s six helpers.** Preserve their preconditions and ownership boundaries as mapped in003.b. Mutable work units remain private to calculation; saved records copy/freeze their fields.
5. **Implement the sequential factory.** `derive_from(source_series, config, rule_tree_ref)` validates raw input, initializes the first work unit, compares each next raw bar with the current merged interval, then absorbs or saves/starts a new unit. The main loop owns `i`, `n`, ID assignment, result appends and EOF save. Absorption advances only `i`; starting a new unit advances `i` and `n`.
6. **Implement explicit initialization behavior.** Apply initialization only to inclusion with unresolved direction. `UP`/`DOWN` set the current direction then absorb the same candidate. `OUTER` takes the outer envelope and retains None. `BOTH` copies independent mutable states and evaluates both complete paths, retaining the upward-initialized main output. `UNSET` stops before consuming the ambiguous candidate and preserves a pending outcome. No default is selected; settle the factory’s return contract without disguising pending/dual results as an ordinary complete series.
7. **Validate completed results.** Require nonempty output; unique integer IDs; finite ordered prices; valid directions; and continuous, nonoverlapping half-open source ranges covering the complete raw input. Reject inclusion between adjacent results, including equal boundaries. Allow nonadjacent inclusion. A one-record result passes the empty adjacent-pair check.
8. **Provide source-grounded explanations.** Record all executed decisions, including those producing no saved record. Map each result position to valid trace indices; explain rules, input evidence, direction changes, merges and source coverage using the exact rule version. DecisionStep’s schema remains unresolved; do not substitute fabricated traces or describe this interface as complete before agreement and verification.
9. **Preserve the display/source distinction.** Place a result at `source_start` and the first raw member’s timestamp. Preserve every raw member through `[source_start, source_stop)`; neither placement nor EOF establishes confirmation time.
10. **Keep components separate.** Proposed algorithm location: `src/chanlab/algo/merged_kline.py`; proposed renderer: `src/chanlab/visualization/merged_kline_plot.py`. Keep file/table/DataFrame adapters outside the algorithm. ChanTable interchange and DataFrame conversion remain explicit later integrations, as in memo013; later Chan detectors are outside this family.
11. **Add the plotting extension.** After selecting the core implementation, implement `plot(**options)` through a separate Plotly helper, following the Appendix. Preserve the frozen core comparison and record plotting checks separately in002.f, as memo013 does.

## 003 — MergedKline family interface
The following is the implementation target from memo009, refined by015; it is not an implemented API. Final constructor signatures, configuration types and factory return types must reflect the resolved contracts.
### 003.a — MergedKline and MergedKlineSeries
**MergedKline members**

| Member | Type | Contract |
|---|---|---|
| `id` | `int` | Unique in the owning result; independent of tuple/raw position. |
| `low`, `high` | `float` | Finite ordered merged bounds, not reconstructed raw OHLCV. |
| `direction` | `Optional[str]` | Up/down or unresolved None; agree concrete string values. |
| `source_start`, `source_stop` | `int` | Nonempty half-open range in the exact raw source; owning series checks bounds. |
| `status` | `str` | Calculation/confirmation state; vocabulary and transitions pending. |
| `confirmed_at` | `Optional[datetime]` | Aware UTC source-evidence time when confirmed; None while unconfirmed. Evidence rule pending. |

**MergedKlineSeries members**

| Member | Type | Contract |
|---|---|---|
| `source_series` | `KlineTSeries` | Exact immutable input object, retained by reference. |
| `klines` | `tuple[MergedKline, ...]` | Nonempty completed result in source order. |
| `config` | immutable config record | Reproducible rule options, including initialization; concrete schema pending. |
| `rule_tree_ref` | `str` | Rule location plus exact version used. |
| `trace` | `tuple[DecisionStep, ...]` | All executed decisions in order; DecisionStep schema pending. |
| `trace_by_point` | `tuple[tuple[int, ...], ...]` | One tuple per result position, containing only valid trace indices. |

**Methods and implementation coverage**

| Owner / method | Required behavior | Planned coverage |
|---|---|---|
| Record `__init__(...)`, `validate()` | Immutable fields; automatic local validation including status/UTC consistency. | Core, after status contract. |
| Series `__init__(...)`, `validate()` | Retain immutable source/results/settings/traces; automatically validate records, full source coverage, adjacent noninclusion and trace alignment. | Core, after trace contract. |
| `derive_from(source_series, config, rule_tree_ref)` | Class method executing015 and retaining raw identity, configuration and trace. | Core; pending/dual-path return shape must be resolved. |
| `__len__()`, `__iter__()` | Count/iterate stored merged records. | Core. |
| `__getitem__(key)` | Integer returns one record; slices return tuples using normal Python indexing, without renumbering IDs/source/trace references. | Core. |
| `get_by_id(feature_id)` | Return the matching record; absent ID raises `KeyError`. | Core. |
| `explain(point_index)` | Explain this result position using recorded decisions, source evidence and versioned rules. | Core, after trace schema. |
| `from_chan_table(table, series_key)` | Class method returning the exact registered series after class/result-context checks. | Deferred table adapter; preserve this target. |
| `to_chan_table(table, series_key)` | Return a new table view registering this series against the same raw snapshot while preserving other features. | Deferred table adapter; registration/conflict rules pending. |
| `to_dataframe()` | Separate compact record DataFrame with integer IDs, source/version context and confirmation times. | Deferred adapter, matching013’s integration boundary. |
| `plot(**options)` | Delegate feature-over-source rendering and return a chart. | Plot extension in001.a/002.f. |

`len(trace_by_point) == len(klines)` and every referenced trace index is in bounds. Structural validation does not replace rule replay: verify derived prices/directions against worked cases and the recorded decisions.
### 003.b — Calculation helpers and adapters
These six helper names/contracts come from015 section002.c; they need not become package-level public APIs.

| Helper | Contract and ownership |
|---|---|
| `work_from_raw(raw, i, direction=None)` | New independent work unit from one valid nonnegative raw position; no ID/counter changes. |
| `has_inclusion(a, b)` | Symmetric inclusive containment on valid intervals, including equal boundaries. |
| `direction_between(a, b)` | Strict up/down for chronologically ordered nonincluded intervals; reject inclusion. |
| `merge_included(current, candidate)` | Same source/path, contiguous single-raw candidate, known current direction; return max/max or min/min merged work without modifying inputs. |
| `merge_outer_boundary(current, candidate)` | Explicit OUTER only, current direction None; return max-high/min-low envelope and retain None. |
| `validate_merged_result(raw, result)` | Check exact source identity, record fields, full source partition and adjacent noninclusion; return None or raise, without repair/reordering. |

Reuse `chanlab.data.kline_csv.read_kline_csv` for input. No new merged CSV contract is assumed. Domain methods delegate future table/DataFrame conversion to adapters.

For future ChanTable projection, record `id` on every raw row in `[source_start,source_stop)`, start marker at `source_start`, end marker at `source_stop-1`, and direction only at the start marker. Keep original OHLCV unchanged; uncalculated groups remain NA, computed-empty ID cells use empty tuples, and unresolved scalar direction remains NA. Series key/class/level/result version and exact source snapshot accompany IDs.[1] The current ChanTable validator rejects non-NA feature columns, so projection requires its own agreed integration change; it cannot be claimed as working merely because merged records exist.

## Appendix — Plotting and contracts to settle
**Plotting plan**
1. Reuse013’s optional Plotly integration and source-price helper where suitable. Render merged low/high intervals or equivalent explicit range marks; the records contain no merged open/close/volume, so do not fabricate candlesticks or merged volume.
2. Proposed convenience options mirror the raw plot: `start`, `stop`, `volume`, `title`. Define bounds as merged-record positions; select the corresponding raw extent without recalculating the algorithm on a truncated input. Anchor each result at its first raw timestamp and show full raw range/ID/direction on hover.
3. Preserve UTC/session gaps. Optional volume belongs to raw bars. Return a Figure with no automatic display/export; let callers write standalone HTML. Reuse the optional dependency mechanism, with a clear installation message when absent.
4. Verify trace arrays against source/results and inspect charts. Record PNG tooling separately; do not make PNG export tools mandatory for the domain classes.

**Open contracts**

| Item | Decision needed before its implementation |
|---|---|
| Initialization/config | Concrete immutable type, accepted values and explicit caller selection; no default chosen by this memo. |
| Factory results | Reconcile009’s series factory with015’s complete, UNSET-pending and BOTH outcomes; retain both paths and original request context. |
| Status/confirmation | Vocabulary, transitions, source evidence and UTC timing; completed batch processing is not automatically confirmed. |
| Trace/explanation | Minimal agreed DecisionStep schema, branch/source evidence, version identifier and mapping;009’s empty DecisionStep definition remains unchanged. |
| Dual-path warning | Difference measure, source-aware alignment, threshold and delivery; unevaluated is not equivalent to no warning. |
| Later adapters | ChanTable registration/conflicts and DataFrame schema; no silent implementation through the raw master’s reserved columns. |
