## 003 — Implemented classes, members and methods
### 003.a — Two classes
The merged-kline family defines **exactly two classes**, following memo009:

| Class | Responsibility |
|---|---|
| `MergedKline` | One immutable merged interval and its original-member range. |
| `MergedKlineSeries` | Own the completed records, source, configuration and trace; calculate, validate, explain, plot and convert. |

Import both from `chanlab.algo.merged_kline`. Existing Kline/KlineTSeries supply raw input; existing ChanTable supplies a table view. They are not additional classes introduced by this family. Configuration, trace events, pending/dual-path data and temporary work are plain data, not classes. Calculation helpers are private methods of MergedKlineSeries; adapters handle file/table/DataFrame/rendering details through its public methods.
### 003.b — MergedKline
**Members:8**

| Member | Type | Meaning |
|---|---|---|
| `id` | `int` | Nonnegative integer ID unique in this result; `MK` prefix is display-only. |
| `low` | `float` | Merged lower bound. |
| `high` | `float` | Merged upper bound. |
| `direction` | `str \| None` | `"up"`, `"down"` or unresolved None. |
| `source_start` | `int` | First raw member index, inclusive; also display placement. |
| `source_stop` | `int` | Raw member end, exclusive. |
| `status` | `str` | Currently only `"unconfirmed"`. |
| `confirmed_at` | `datetime \| None` | Currently None; confirmation rules remain unselected. |

**Constructor and methods**

| Method | Kind | Behavior |
|---|---|---|
| `MergedKline(id, low, high, direction, source_start, source_stop, status="unconfirmed", confirmed_at=None)` | Constructor | Store immutable fields and validate automatically. |
| `validate()` | Public instance method | Check integer IDs/indices excluding bool, finite ordered bounds, nonempty range, direction and unconfirmed/None contract. Source upper bounds are checked by the owning series. |
| `__post_init__()` | Automatic hook | Calls validate() after dataclass construction; callers do not call it. |
| `_validate_integer(value, name)` | Private static method | Shared nonnegative-integer check. |

### 003.c — MergedKlineSeries
**Members:6**

| Member | Type | Meaning |
|---|---|---|
| `source_series` | `KlineTSeries` | Exact original immutable raw object. |
| `klines` | `tuple[MergedKline, ...]` | Nonempty completed records in source order. |
| `config` | read-only mapping | Detached configuration data, currently `{"initialization": "UP"}` or another explicit allowed policy. |
| `rule_tree_ref` | `str` | Nonblank rule location/version supplied by caller. |
| `trace` | tuple of read-only mappings | Executed rule/index/before/candidate/after evidence, including decisions without a saved output. Nested interval data is also read-only. |
| `trace_by_point` | `tuple[tuple[int, ...], ...]` | One nonempty tuple of trace indices per record position; every trace event must be covered. |

**Constructor and public methods**

| Method | Kind | Return / behavior |
|---|---|---|
| `MergedKlineSeries(source_series, klines, config, rule_tree_ref, trace, trace_by_point)` | Constructor | Retain exact raw reference; copy/freeze configuration, records and trace data; validate automatically. Normally use a factory below. |
| `derive_from(source_series, config, rule_tree_ref)` | Class method | Calculate from KlineTSeries or ChanTable; passing a table uses its exact raw source. Normally returns MergedKlineSeries. Ambiguous UNSET/BOTH outcomes use the plain-data contract below. |
| `from_chan_table(table, series_key)` | Class method | Retrieve the exact registered series after class/source/context validation; absent key raises KeyError. No recalculation. |
| `validate()` | Instance method | Check source/records, unique IDs, full continuous source partition, adjacent noninclusion, config/rules and complete valid trace mapping. Structural validation is not a full algorithm replay. |
| `__len__()` | Sequence method | len(series): merged record count. |
| `__iter__()` | Sequence method | iter(series): chronological records. |
| `__getitem__(key)` | Sequence method | Integer → record; slice → tuple. Normal negative indexing/slicing; no renumbering. |
| `get_by_id(feature_id)` | Instance method | Return the matching record; missing valid ID raises KeyError, invalid ID raises ValueError. |
| `explain(point_index)` | Instance method | Human-readable record/source/rule information and linked before/after evidence for a result position. |
| `to_chan_table(table, series_key)` | Instance method | New registered table preserving the original view and other keys. Require exact same raw source; reject same-key/different-object conflicts. |
| `to_dataframe()` | Instance method | Detached compact pandas DataFrame, one row per record. attrs retain config, source digest/provenance, rule/result version and trace mapping. Requires dataframe extra. |
| `plot(*, start=None, stop=None, volume=True, title=None)` | Instance method | Plotly Figure over original raw prices, selecting merged positions without recomputation. Empty slice raises ValueError. Requires plot extra. |

**Automatic hook and private implementation methods**

| Method | Responsibility |
|---|---|
| `__post_init__()` | Freeze input data and call validate(). |
| `_validate_config(config)` | Require explicit initialization mapping; reject unsupported keys/policies. |
| `_freeze_data(value)` | Recursively detach/freeze configuration and evidence containers. |
| `_work(...)`, `_change(work, **changes)` | Construct or replace validated private interval data. No work class. |
| `_work_from_raw(raw, i, direction=None)` | Initialize one private work interval from a raw bar. |
| `_has_inclusion(a, b)` | Symmetric inclusive containment, including equality. |
| `_direction_between(a, b)` | Strict up/down for a nonincluded chronological pair. |
| `_check_pair(current, candidate)` | Same raw snapshot, continuous ranges and one included raw candidate. |
| `_merge_included(current, candidate)` | Known direction: max/max upward or min/min downward. |
| `_merge_outer_boundary(current, candidate)` | Explicit unresolved OUTER envelope, retaining None. |
| `_validate_step(step, raw)` | Validate decision fields, supported rule/index and evidence source/ranges. |
| `_validate_result(raw, result)` | Complete source coverage, record/ID checks and adjacent noninclusion. |
| `_advance(...)` | Own sequential processing, initialization, independent dual paths, ID assignment, saving and EOF. |

Private methods are implementation details; callers use the public factories/methods. They add behavior to the existing classes, not new classes or public module functions.

**Factory data contract**

Pass an ordinary dict such as `{"initialization": "UP"}`. Allowed policies: UP, DOWN, OUTER, BOTH, UNSET; no default. Policies apply only to inclusion while direction is unresolved.

| Situation | Return |
|---|---|
| Complete single-path calculation, including BOTH/UNSET when no ambiguous startup occurs | MergedKlineSeries. |
| UNSET reaches ambiguous startup inclusion | Read-only mapping with `kind="pending"`, `source_series`, `config`, `rule_tree_ref`, `saved`, `current`, `candidate`, `raw_index`, `trace`. Candidate is unconsumed; this is not a completed series. |
| BOTH reaches ambiguous startup inclusion | Read-only mapping with `kind="dual"`, `main` upward-initialized series, `comparison` downward-initialized series, `requested_config`, `warning_evaluation="not_evaluated"`. |

The special mappings preserve memo015’s pending/dual semantics without introducing outcome classes. Their nested data is read-only. To inspect/plot/export a dual result, call methods on `outcome["main"]` or `outcome["comparison"]`. Pending data has no resume API and cannot be exported as a completed feature series.

```python
from hashlib import sha256
from pathlib import Path
from tempfile import TemporaryDirectory
from chanlab.algo.chan_table import ChanTable
from chanlab.algo.merged_kline import MergedKline, MergedKlineSeries

folder = Path("samples/chan_table")

    next(folder.glob("*chan_table*.csv")), next(folder.glob("*context*.csv"))
)
rule_path = Path("docs/memo/memoWX_015_Chan_mergedkline.md")
rule_ref = "memo015:sha256:" + sha256(rule_path.read_bytes()).hexdigest()
series = MergedKlineSeries.derive_from(raw, {"initialization": "UP"}, rule_ref)
assert isinstance(series, MergedKlineSeries)
assert series.source_series is raw
assert len(raw) == 10060 and len(series) == 6200
bar = series.get_by_id(series[0].id)
assert isinstance(bar, MergedKline)
members = raw[bar.source_start:bar.source_stop]
assert members
print(series.explain(0))
base = ChanTable.from_source_series(raw, context)
view = series.to_chan_table(base, "merged")
```

**From existing ChanTable data, then write/read**
```python
base = ChanTable.read_csv(
    next(folder.glob("*chan_table*.csv")), next(folder.glob("*context*.csv"))
```

CSV write/read belongs to the existing ChanTable; MergedKlineSeries owns registration/retrieval. Registered features require both row CSV and context CSV for lossless bounds/config/rules/trace restoration. In-memory retrieval preserves exact object identity; reading from disk creates new objects tied to the newly loaded source. The four MK columns are a raw-time view, not the authoritative record storage. DataFrame export does not provide an inverse importer, and ordinary DataFrame CSV export loses attrs.

**Handle any initialization policy**

## Appendix — Contracts and reproduction
1. **Initialization:** explicit configuration mapping; no project default. BOTH/UNSET return tagged read-only data only if ambiguous inclusion is encountered.
2. **Confirmation:** only unconfirmed/None supported. EOF completion and first-member display placement are not confirmation evidence.
3. **Trace:** read-only mappings retain rule and before/candidate/after evidence. Nested work data contains raw reference, low/high, direction and source_start/source_stop. General DecisionStep remains deferred; this is not a cross-feature schema.
4. **Warning:** BOTH retains both full paths and original request; source-aware difference scoring/threshold/delivery remain unimplemented and explicitly unevaluated.
5. **Adapters:** implemented in002.g/003.c–003.d. Fixed41-column master schema remains; authoritative feature data uses the versioned context entry. Other concept adapters and expanded per-key CSV columns remain future work.
6. **Plotting:** existing optional Plotly extra; UTC/session gaps retained; raw volume only. PNG export uses temporary Kaleido/local Chrome tooling, not a new runtime requirement.
7. **Reproduction:** [current refactor verification](../../artifacts/mas/merged-kline-two-class/verify.py) compares old/new behavior and prior persisted-context compatibility. [Original verify.py](../../artifacts/mas/merged-kline-family/verify.py) reruns frozen historical comparisons and current chart outputs.
