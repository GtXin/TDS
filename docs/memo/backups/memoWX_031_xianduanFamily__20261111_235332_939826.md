# Xianduan family implementation plan
## 000 — Scope and current result
参考memo028的结构与实施顺序，准备线段领域类、集成、验证和图集计划。[1] 类设计以memo009为核对依据。[2] 本轮实现及验证已完成，实际记录见002；可复现证据与任务见[6]。

本轮线段算法依据为memo030当前XD030-E：实际相邻S/T/U绑定破坏证据，多源选路目标为“已确认线段数最多→同段数已确认几何终点最晚”；两者相同按固定遍历保留先者，起点不评分。[4] 上游笔仍按029生成。[3] 实施时记录两份规格快照与哈希，不修改029／030。030现有隔离试算是参考证据，不代替本轮生产实现验收。

**默认配置：weak Bi＋weak Xianduan。** 本轮默认流水线显式传入笔distance_mode=weak（中心距至少3），线段xd_mode省略时取weak（不施加7a端点更极端条件，其余条件不变）。两个模式独立，支持显式四组合；传入既有BiSeries时尊重并校验其实际模式，不暗中重算。009／028及现有Bi接口的strong默认差异在实施时同步核对，计划将Bi工厂缺省也改为weak，并补调用方回归；运行默认已改为weak／weak；显式strong及既有持久化模式保持可用。

## 001 — Implementation plan
### 001.a — Implement the Xianduan family
1. 核对009的Xianduan／XianduanSeries设计与030 XD030-E规格，列明成员、来源、公开方法、状态及解释合同；有冲突先记录并讨论。
2. 计划在 `src/chanlab/algo/` 实现共享算法，保持独立于API和网站。输入保留确切BiSeries及其分型、合并和原始来源链；ID、序列位置、端点锚点与确认时间分别处理。
3. 按030002.a–f建立定义到代码映射：枚举全部Shape候选；第一类及直接破坏绑定实际S/T，第二类绑定实际S/T/U分界和成员；同侧包含、同价取最早、严格分型、触点交集及失效守卫逐项保留依据。Shape通过不代表确认，替换T／U必须重验。
4. 所有合法起点共同参与；以完整候选链作参考基线，生产相邻对状态(a,b,c)仅在无跨T剩余依赖的局部充分性前提下压缩。比较(count,已确认末端)，保留best／prev和稳定遍历；回溯后从原笔独立重算逐对证据。输出连续已确认前缀，未确认T／U尾部单列且不计数。unsupported和资源超限明确报告，不将局部最优称作原文全局最优；固定快照无永久提交／续读承诺。
5. 先实现可直接核对的基线，再评估优化；复杂度按实际状态数、候选数和范围扫描成本推导，记录时间和内存。
6. 核对后完成explain、DataFrame、ChanTable、CSV/context和绘图集成；不改变上游已选笔路线来适配线段结果。

## 003 — Implemented classes, members and methods
### 003.a — Class count and scope
实现Xianduan／XianduanSeries两个不可变领域类，定义于[通用算法模块](../../src/chanlab/algo/xianduan.py)。特征元素及DP状态为私有实现，API、表和绘图不复制识别算法。[2,4]
### 003.b — Xianduan
成员为id:int、source_start/source_stop:int（确切Bi半开成员范围）、start_price/end_price:float、direction:str、status="confirmed"、confirmed_at:UTC datetime。构造自动validate，检查非负整数／奇数至少三笔／有限价格／方向／UTC证据时间；来源和破坏由series复核。
### 003.c — XianduanSeries
成员为source_series:BiSeries、items:tuple、config（当前仅xd_mode，默认weak）、rule_tree_ref、trace、trace_by_point及tail（实际未确认后段／支持段范围）。配置、trace和记录递归冻结。

| 方法 | 行为 |
|---|---|
| derive_from／validate | 固定快照识别；从原笔重新验收实际S/T/U及证据、记录、来源和trace对齐。手工构造的合法series不自动保证全局最优。 |
| len／iter／getitem／get_by_id | 标准位置、负下标、切片元组与结果内整数ID查询；缺ID抛KeyError。 |
| explain | 规则、实际源Bi模式、XD模式、选中段、绑定证据、tail与未覆盖源Bi范围。 |
| pending_candidates／unresolved_ranges | 未确认Shape候选及未覆盖半开源Bi范围；不计入已确认items。 |
| to_chan_table／from_chan_table | 同一raw快照独立key注册，保留确切上游；反向查询返回注册对象。 |
| to_dataframe | 独立8列记录、规则／模式／源指纹attrs；持久化仍用CSV＋context。 |
| plot | 既有raw／merged／全部FX／Bi图上叠加XD实线与tail虚线；窗口不重算。 |

私有scanner执行Shape和本地事件，selector执行多源相邻对best／prev；辅助范围缓存不作为领域成员持久化。
### 003.d — Object workflow and implementation boundary
KlineTSeries→MergedKlineSeries→FenxingSeries→BiSeries（省略模式为weak）→XianduanSeries（省略xd_mode为weak）→解释／DataFrame／ChanTable／绘图。实际源Bi为strong时，XD不会偷偷改为weak源笔。调用方显式四组合，保存的context记录有效模式及来源指纹。
