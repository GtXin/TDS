## 2. 本次发现的问题：前三笔判断与起点放弃

**[结论] 0032把前三笔的端点条件当作起步门槛，并在失败后立即换起点；这条推论的原文依据不足。** 目前定位到S2.a／S2.c，尚不能认定两套算法的全部差异都来自这里。[^memo-start]

### 2.a 从图中的B8、B9、B10看问题

![B8–B10共同价格区间及0032从端点门槛失败到换起点的推论问题](../../artifacts/experiments/chan_theory/memo0039_2a_three_bi_problem.png)

黄色带表示三笔价格区间的交集；B10终点仍比B8终点高51。右侧只演示0032局部条件的处理，问题在于由“未创新低”直接转到“放弃起点”。

这里沿用第1节的全局笔号，三笔首尾相连：

```text
笔号    方向    起价 → 止价       价格区间
B8      下降    3116 → 3005     [3005, 3116]
B9      上升    3005 → 3103     [3005, 3103]
B10     下降    3103 → 3056     [3056, 3103]
```

三笔的共同价格区间为`[max(3005,3005,3056), min(3116,3103,3103)] = [3056,3103]`，宽度47，确实有重叠。但B10的终点3056高于B8的终点3005，第三笔没有创新低，且B10的整个价格区间被B8包含。

将这三笔单独代入0032的局部起步条件，会得到：

```text
以B8起点3116检查前三笔
├── 三笔有共同价格区间 → 通过重叠条件
└── 第三笔终点3056 ≤ 第一笔终点3005 → 不成立
    └── 现行S2.c：起点移到B9起点3005，再检查B9–B11
        └── 问题：端点条件失败，不能直接推出应放弃B8起点
```

这是对S2条件的局部代入，不表示memo算法的完整入口一定按此路径到达B8。KWX图中的X0则是完整输入计算后的B8–B20，终点2766；不能据此说只看到B10时，程序已经确认了X0。[^kwx-output]

### 2.b 原文需要连同前提一起读

- **第65课：** 原文既要求前三笔重叠，也说符合所述条件后“那么必然会形成一线段”。此前只概括为“必要条件”不完整；但这也没有把第三笔终点直接指定为线段终点。
- **第67课：** 后续划分以精确的特征序列规则为基础。特征序列由与所考察线段方向相反的笔组成，每笔以高低价区间参与判断；还要处理适用的包含关系、分型及缺口，才能判断分界。
- **第71课：** 第三笔完全在第一笔内时，原文明确讨论了方向未定的情况；其前提是**从转折点开始的第一笔已经破坏前线段**。[^original-lessons]

在第71课这个特定前提下，原文给出的后续结果是：

```text
第一笔已破坏旧线段，第三笔完全在第一笔范围内
└── 固定第一笔的起点与终点，观察后续首先突破哪一端
    ├── 先突破第一笔终点 → 新线段成立，旧线段结束
    ├── 先突破第一笔起点 → 旧线段延续，新线段没有出现
    └── 尚未发生上述突破 → 结果尚不能确定，继续观察
```

这棵树只概括该段原文，未扩展平价等实现边界。B8是KWX首条输出线段的起笔，前面的B0–B7未被划入输出线段；我们尚未证明它具备上述“已破坏旧线段”的前提。因此，不能直接把这棵树当成数据首段的通用初始化算法。

![第71课独立示例：第三笔被包含后先破第一笔终点或起点的两种结果](../../artifacts/experiments/chan_theory/memo0039_2b_lesson71_outcomes.png)

**[独立示例]** 两图共享`100→60→90→70`的前三笔，第三笔`[70,90]`在第一笔`[60,100]`内。左图后续`70→80→55`先跌破60，右图后续`70→105`先涨破100。这里给定“第一笔已对旧上升段造成笔破坏”的前提，未画旧段内部笔来验证它；这不是B8的后续数据，也没有把此前三笔直接画成已成立的新下降段。[^problem-figures]

### 2.c 两种“包含”不能混用

**原笔包含**是两笔价格区间一大一小的关系；这里是B8包含B10。**特征元素包含**则要求先明确正在考察哪条线段，并识别属于同一特征序列的元素，不能只见区间包含就合并。[^original-lessons]

例如，尝试考察下降线段时，取的是B9、B11等上升笔，B8、B10不属于它的这组特征元素。B9的区间`[3005,3103]`包含B11的`[3056,3080]`，与“B8包含B10”是两组不同对象；能否及如何合并，还须核对元素归属与处理方向。

## 3. 局部算法：第三笔未升到B，保留A后怎么办

**先判断A是否成为新旧两段的分界：固定第一笔的起点A、终点B，按时间读后续笔，看最先突破哪一端。** 后续突破是判断证据，分界位置仍是A；不能把首次突破点直接当作新段终点。[^original-lessons]

### 3.1 入口：升、降、升，第三笔完全在第一笔内

**给定前提：** 已有一条正在考察的下降线段，在A向上转折；第一笔`A→B`已经对旧段造成笔破坏，但旧段是否结束尚未确定。本节不验证旧段内部结构，也不处理没有已知前段的数据初始化。

本节的B1、B2……是从A开始的**局部笔号**，与第1、2节的全局笔号无关。四个点本身不能证明上述旧段前提。

```text
B1：A100 → B130（升）
B2：B130 → C110（降）
B3：C110 → D120（升，未升到B）
```

- **已知形态：** `A<C<D<B`，因此B3的区间`[C,D]`完全在B1的区间`[A,B]`内，三笔交集就是`[C,D]`。不需要再把重叠作为独立关卡。
- **当前身份：** A是待判断的新段起点；D只是第三笔终点，尚不是新线段终点。B1–B3及后续原笔均保留。
- **固定与推进：** 本次判断始终固定`A=100、B=130`，检查位置从B4开始逐笔前移。后续低点、高点不替换这两个参照。

若不足三笔、旧段前提未成立，或不属于`A<C<D<B`，就尚未进入本分支；本章不据此决定换起点。`C=A`、`D=B`等入口边界也不在当前已核对范围内。

### 3.2 判断树：读B4，再读B5……直到首个结果

`P`是当前读到的那一笔的终点价格。输入是一份按时间排列、首尾相连、升降交替的完整笔列表；本节按这些笔的终点检查结果，不判断尚未完成的笔。每次只前移检查位置，不移动A、B。

```text
3.1 第一笔已对旧下降段造成笔破坏，且A<C<D<B
└── 3.2 固定A、B；先取B4，随后按顺序取下一笔
    ├── 已无下一笔
    │   └── 3.3.c 当前资料不足以判定；结束本次局部检查
    └── 取得当前笔终点P
        ├── P>B：首先突破第一笔终点
        │   └── 3.3.a 新上升段从A成立；结束本次局部检查
        ├── P<A：首先突破第一笔起点
        │   └── 3.3.b 旧下降段延续；结束本次局部检查
        ├── A<P<B：仍在第一笔内部
        │   └── 保留A、B及原笔；取下一笔，回3.2
        └── P=A或P=B
            └── 3.3.d 等号出口未决；本稿尚不能规定下一动作
```

**按发生先后决定结果。** 在已定义的严格突破路径上，第一次`P>B`或`P<A`就结束本次局部检查，不继续比较另一端来推翻结果。若此前遇到未决的等号分支，不能跳过它后声称本稿已确定结果。

### 3.3 返回什么，之后处理什么

- **3.3.a 新上升段成立：** A成为旧下降段的终点、新上升段的起点。B1及后续已读笔保留为从A向上发展的走势记录；本章不输出一条终点已确认的新线段。返回“新段从A成立”及首次突破的证据笔；新段最终在哪里结束，下一步交给第67课的线段划分规则，当前章节尚未展开这一后续算法。
- **3.3.b 旧下降段延续：** 本次从A起的新上升段没有形成，A不作为这次的新旧段分界。B1及后续已读笔属于旧段延续过程，原始笔不删除；返回“旧段延续”及首次突破的证据笔，后续继续考察旧段，不在这里规定换到B2或其他起点。
- **3.3.c 输入耗尽：** 返回“本次资料尚不能确定结果”，连同A、B和最后检查到的笔。若继续人工推演，补充笔后从下一笔回3.2；这只是本分支的推演位置，不表示现有KWX或0032代码会保存并恢复该状态。
- **3.3.d 等号未决：** 保留原始资料，标明在哪一笔触及A或B；当前未决定继续、成立或否定。先核对原文边界，才能补上出口。此前“分型严格大于／小于”的决定，不能自动代替这里的突破规则。

### 3.4 一条主例走到底

沿用3.1的前三笔，给定同一个旧段前提：

```text
点名    A     B     C     D     E     F     G     H
价格   100   130   110   120   105   125   108   135
笔序      B1    B2    B3    B4    B5    B6    B7
```

| 当前笔 | 终点比较（A=100、B=130不变） | 结果与下一步 |
|---|---|---|
| B4：120→105 | `100<105<130` | 取B5，回3.2 |
| B5：105→125 | `100<125<130` | 取B6，回3.2 |
| B6：125→108 | `100<108<130` | 取B7，回3.2 |
| B7：108→135 | `135>130`，此前没有突破或触及两端 | 进入3.3.a：新上升段从A成立，本次检查结束 |

到B7才具备本例的成立证据，分界仍在A；H135不是据此自动确认的线段终点。

**独立失败例：** 仍以`100→130→110→120`开始，仅将后续改为B4`120→95`。因为`95<100`先发生，进入3.3.b：旧下降段延续，这次新上升段未形成。

**资料与边界：** 主例若只给到B5，就走3.3.c，不能把F125当结果。若B4止于100，或B5恰好止于130，则落入3.3.d，当前稿不补造等号行为。

**[验证范围]** 已核对原文前提、上述数值及分支去向；这是一个仍有等号出口未决的局部算法稿，未进行完整可执行验证。首段初始化、第67课后续终点算法及两套现有实现的修改均未完成，本章不宣称实现就绪。
