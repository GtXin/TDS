#### 1.2 Symbols and Annotations

| 记号 | 含义 |
|---|---|
| `B1 … BM` | 按时间排列的M笔 |
| `P1 … PN` | 笔的端点，每个点包含时间位置和价格 |
| `X、Z` | 当前处理的线段、下一条线段 |
| `x_s、x_e` | X的起点、终点 |
| `z_s、z_e` | Z的起点、终点 |
| `S1 … SL` | 按时间排列、已经成立的L条线段 |

- 笔连续相接时：`Bi = Pi → P(i+1)`，`N = M + 1`。
- X与Z相接时：`x_e = z_s`；何时将X或Z记入S，由流程决定。

#### 1.3 判断、行动与复用

流程树采用 **`判断结果 → 行动`**：箭头左侧是判断结果，右侧是执行的行动。

复用同一检测块时，判断规则保持一致；行动可随调用入口不同，但须明确注明。
例如，复用2.3时，2.3.a按入口执行：

| 调用入口 | 判断结果 → 行动 |
|---|---|
| 2.2.a 有首段 | X不成段 → 移动起点；回2.3 |
| 2.2.b 无首段 | X不成段 → 保留起点、移动终点；回2.3 |

#### 2.2. Modular Checkers 

#### 2.2.1 线段的定义

几何学定义
> 1.  起点至少3笔
> 2. 起点前3笔重合 min(max(Bi's)) - max(min(Bi's)) （其实Bi上下交替前提下，这个条件在1 3 满足的时候必然没必要）
> 3. 向上笔 x_e > x_s； 向下笔 x_e < x_s
> 4. 线段连续，除了最后一个线段，一个线段的终点必然是另一个反向线段的起点
> 5. 一个线段里不能包括另一个反向线段的一部分
> 6. 终点的其他判据待定

Note: 
- 有无缺口的特征序列的判断或不需要，假设第一线段B1B2B3候选 B4下降有缺口; 
- 缠论建议 有缺口 力度不够 B5 B7 B9 ....找底；无缺口 B2 B4 B6找顶 
- 我的观点 因为第二线段终点必有第三线段所以有拐点 所以在B2 B4 B6 顶分型的情况下，B4>B6 但是B6后由第三线段存在确保转向。所以 有无缺口都可以B2 B4 B6判断


#### 2.2.2 特征序列的算法

固定候选点 `Pj`，保留点前的左元素，从点后第一根反向笔开始处理包含，取得交给 `_006` 判断分型的三个元素。

Input: 本轮待检测方向 `D`、候选点 `Pj`、按时间排列的笔 `B1 … BM`、点前已标准化的最后一个特征元素 `E0`、已确定的包含处理方向 `d`。
Output: 三元素 `E0、E1、E2` 及来源笔、读到的位置；或 `突破(Pr)`、`数据不足`、`前置输入不符`。本节返回调用方，不直接确认线段或移动起点。

- 特征元素是反向笔的价格区间 `[L,H]`，`L=min(起价,终价)`，`H=max(起价,终价)`；合并元素另保留全部来源笔编号。
- `D` 向上取下降笔，`D` 向下取上升笔。`d` 由包含前相邻、无包含关系的两个元素确定：后者高低点都更高则向上，都更低则向下；没有这对参照时不自行设定 `d`。
- `Bi = Pi → P(i+1)`，所以候选点 `Pj` 后第一笔为 `Bj`。本轮固定 `Pj、E0、d`，只推进读取下标 `k`、更新 `E1`。
- 包含：`La ≤ Lb 且 Ha ≥ Hb`，或反过来；边界相等也算包含。仅部分重叠不算包含。
- 合并：`d` 向上取 `[max(La,Lb), max(Ha,Hb)]`；向下取 `[min(La,Lb), min(Ha,Hb)]`。只更新派生元素与来源，原始笔不变。

├ 2.2.2.1 前置输入检查
	├ 2.2.2.1.a 缺少候选点、E0或d -> 返回前置输入不符；由调用方补齐
	└ 2.2.2.1.b 前置输入齐全 -> 检查点后第一笔Bj
		├ 2.2.2.2 点后第一笔检查
			├ 2.2.2.2.a Bj尚不存在 -> 返回数据不足；保留候选点
			├ 2.2.2.2.b Bj与D同向 -> 返回前置输入不符；核对候选点位置
			└ 2.2.2.2.c Bj与D反向 -> E1 = Bj的区间；来源 = [Bj]；k = j+1
				├ 2.2.2.3 按时间读取下一笔
					├ 2.2.2.3.a k > M -> 返回数据不足及已有元素；保留候选点

							├ 2.2.2.4.b D向下且价P(k+1) < 价Pj -> 返回突破(P(k+1))

											└ 2.2.2.6.b 无包含 -> E2 = T；来源 = [Bk]；返回三元素及当前位置k

[example] 向上候选点 `P4=140`，取下降笔；本例的 `E0=B2` 已标准化。

```text
点： P1   P2   P3   P4   P5   P6   P7   P8   P9
价：100  123  110  140  120  138  125  135  122

E0 = B2 = [110,123]；E1 = B4 = [120,140]
B2 → B4 的高低点都抬高，本例 d = 向上
B5同向，未突破140 → 不加入；继续读B6
B6 = [125,138] 被E1包含 → E1 = [125,140]，来源[B4,B6]
B7同向，未突破140 → 不加入；继续读B8
B8 = [122,135] 与新E1无包含 → E2 = B8；返回给_006
结果：E0=[110,123]，E1=[125,140]，E2=[122,135]；已读取到B8终点P9
```

Note:
- 本轮不跨候选点合并 `E0、E1`；`E0` 本身可以来自点前多笔的既有包含处理。[71]
- 三元素齐备不等于分型成立；严格分型条件由 `_006` 检查。包含允许等号，不改变分型须严格比较的约定。
- 合并后须使用新值判断缺口：本例合并前 `123 ≥ 120`，合并后 `123 < 125`，缺口状态随之改变。
- 数据不足不否定候选点；新增笔后，由调用方以同一候选点及前置输入重新调用本节。若返回突破点，由调用方更新候选后重新调用。
