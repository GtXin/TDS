1. 定义
三元素：连续3根K线，每根K线价格区间只使用 最高/最低 价记录，不记录 开盘/收盘 价。
包含关系：两个相邻元素，一个的区间完全包住另一个。边界相等也算；区间完全相同时，互相包含。
单向包含：只有一方包含另一方，不包括区间完全相同。

2. Knowledge tree（判断树）
三元素A/B/C；H 高点；L 低点；stop 结束当前判断；goto 转至指定节点。
i = 1

3. 包含判定
    3.1 数据检查 （最少3根K线元素）
        3.1.a 元素不足 -> 数据不足 i = i + 1; goto 3.1
        3.1.b 元素齐全，但价格缺失 -> 数据无效; stop
        3.1.c 元素齐全，最高/最低价格都确定; goto 3.2
    3.2 包含处理
        3.2.a 1/2元素
            3.4 AH < BH
                3.4.a AL < BL -> 上涨; goto 3.2.b
                3.4.b AL = BL -> 单向包含; goto 3.1.a
                3.4.c AL > AL -> 单向包含; goto 3.1.a
            3.5 AH > BH
                3.5.a AL < BL -> 单向包含; goto 3.1.a
                3.5.b AL = BL -> 单向包含; goto 3.1.a
                3.5.c AL > AL -> 下跌; goto 3.2.c
        3.2.b 2/3元素
            3.6 BH < CH
                3.6.a BL < CL -> 上涨; goto 3.1.a
                3.6.b BL = CL -> C对B包含 取BL-CH; goto 3.9.a
                3.6.c BL > CL -> C对B包含 取BL-CH; goto 3.9.a
            3.7 BH = CH
                3.7.a BL < CL -> B对C包含 取CL-CH; goto 3.9.c
                3.7.b BL = CL -> B和C互相包含 取CL-CH; goto 3.9.c
                3.7.c BL > CL -> C对B包含 取BL-CH; goto 3.9.a
            3.6 BH > CH
                3.8.a BL < CL -> 下跌; goto 3.1.a
                3.8.b BL = CL -> B对C包含 取CL-BH; goto 3.9.b
                3.8.c BL > BL -> B对C包含 取CL-BH; goto 3.9.b
        3.2.c 2/3元素
            3.6 BH < CH
                3.6.a BL < CL -> 上涨; goto 3.1.a
                3.6.b BL = CL -> C对B包含 取CL-BH; goto 3.9.b
                3.6.c BL > CL -> C对B包含 取CL-BH; goto 3.9.b
            3.7 BH = CH
                3.7.a BL < CL -> B对C包含 取CL-CH; goto 3.9.c
                3.7.b BL = CL -> B和C互相包含 取CL-CH; goto 3.9.c
                3.7.c BL > CL -> C对B包含 取BL-CH; goto 3.9.a
            3.6 BH > CH
                3.8.a BL < CL -> B对C包含 取BL-CH; goto 3.9.a
                3.8.b BL = CL -> B对C包含 取CL-CH; goto 3.9.c
                3.8.c BL > BL -> 下跌; goto 3.1.a
    3.3 包含处理后新元素
        3.9.a BL CH -> 包含后取 第二K线最低至第三K线最高
        3.9.b CL BH -> 包含后取 第三K线最低至第二K线最高
        3.9.c CL CH -> 包含后取 第三K线最低至第三K线最高
